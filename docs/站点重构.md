# 在线演示站的这次重构

> 2026-11-01。把 \`index.html\` / \`app.js\` / \`app.css\` 从"能用的工程看板"改成
> "能对外讲的演示站"，同时把提交进仓库的 83 MB 图片压到 8 MB、首屏 JSON 从 153 KB(gzip) 降到 23 KB。
> 页面仍然是零构建、零依赖、零 CDN，\`file://\` 双击可用。

## 1. 改了什么

### 1.1 信息架构：8 个页签 → 11 个页签

原来的第一个页签直接是查看器：访客落在地上就开始拖滑块，不知道这是什么。
现在先讲清楚"同一时刻六种传感器"，再往下钻。

| 页签 | 新增 / 改动 |
|---|---|
| **首页** | 新。1440×1080 主视觉交叉淡入、"同一帧 · 六种传感器"墙、光照天气对照、"为什么必须同一时刻"、图鉴预览、六个深度入口 |
| 数据集 / 多模态 / SAR / 导引头 | 保留原有能力，重排版面；缩略图走缩略胶片条 + 原生惰性加载 |
| 点云 | 修了**投影缩放错误**（见 2.1）；新增按包围盒自动取景、深度着色、包围盒线框 |
| 雷达 | 修了**显示全黑**（见 2.2）；新增 P90–P99.9 色标拉伸与开关 |
| **图鉴** | 新。20 张技术图，来自 \`tools/make_figures.py\`，可点开看大图与数据来源 |
| 物理实验室 | 原"参数实验"改名 |
| **管线** | 新。六步数据流 + 离线命令 + YOLO 套件规模 |
| 关于 | 合并"原理与离线部署"，更新自检项数（20 → 50） |

每个页签都是真 URL（\`#/sar\`），前进后退可用，可直接分享到某一页。

### 1.2 首屏与视觉

* 新增 \`assets/hero/\`：3 场景 × 可见光/长波红外，1440×1080 重渲（\`scenes/hero_*.json\`，
  只改分辨率与采样数，FOV/光照/几何原样），另加低太阳高度与降雨两版。
* 首屏主视觉用这套高分辨率图，降级路径：\`assets/hero/index.json\` 不存在时自动回落到
  manifest 里的帧，页面不会空。
* 统一设计令牌（背景 / 面板 / 线 / 文字 / 信号色 / 字号阶梯），所有页签共用；
  正文 14→15 px，长段落限宽 860 px，暗色对比度按可读性调过一轮。

### 1.3 性能

| 项 | 之前 | 现在 |
|---|---|---|
| 图片 | 668 张 PNG，83.4 MB | WebP 6.9 MB + 420 px 缩略图 1.2 MB |
| manifest | 646 KB（首屏 gzip 153 KB），含全部点云 | 182 KB（gzip 23 KB），点云拆到 \`data/cloud/<场景>.json\` |
| 首屏脚本 | 无条件 \`<script boot.js>\`（632 KB 内联 JSON） | 仅 \`file://\` 时注入；http(s) 走 \`fetch(manifest.json)\` |

所以"重新导出"不会让站点胖回去。

## 2. 修掉的缺陷

### 2.1 点云视图全黑

原实现把厘米坐标除以一个固定常数（\`* 0.06\`）再乘画布尺寸，等效缩放系数对 40 m 的车
和 900 m 的无人机差 20 倍，结果点全部落在画布外——页面显示"绘制 78 点"但一片黑。

现在：按点云包围盒的 85 分位半径自适应取景（少数远场杂点不会把目标压成几个像素），
另画包围盒线框做深度线索，点按深度做衰减着色。

### 2.2 雷达距离-角度图接近全黑

导出的原始图动态范围 0–103、均值 4、P99 = 13：按线性显示就是一块黑。原页面直接贴原图，
"目标在哪里"完全靠读数猜。

现在在浏览器里做显示拉伸（只改显示像素，不改数据）：窗口取 P90–P99.9，
套一条示波器风格色标，并在标签里写明窗口。\`file://\` 下 canvas 读像素会因跨域污染抛错，
已 try/catch 回退到原图。

### 2.3 对照页被压成半宽

\`#cmpViewer\` 用 \`aspect-ratio\` + \`max-height\` 约束，浏览器会把高度上限**传递给宽度**，
于是 4:3 的框在 1500 px 页面上被压成 933 px 宽。改成显式 \`width:100%\` + 固定高度，
由 \`object-fit\` 负责上下留边。

### 2.4 其他

* 导引头左上角状态文字压在亮天空上不可读 → 加双层文字阴影。
* 首页嵌套 \`<section class="band">\` 被 \`section{display:none}\` 规则误伤 → 规则收紧到 \`main>section\`。
* 图鉴 / 主视觉在 file:// 下不可用 → 页面给出说明而不是空白，主视觉回落到 manifest 帧。

## 3. 怎么重现

\`\`\`powershell
# 图鉴（20 张，写 assets/figures/）
env\Scripts\python.exe tools\make_figures.py

# 主视觉（3 场景 × 6 模态 1440x1080，写 out/hero_*）
env\Scripts\python.exe -m simkit gen -c scenes\hero_ground_vehicle.json -o out\hero_ground_vehicle -n 1 -s optical,ir,radar,lidar,sar

# 站点数据 + 压缩
env\Scripts\python.exe tools\export_web.py . out      # 内含 opt_images 调用
env\Scripts\python.exe tools\opt_images.py            # 单独重跑也可以

# 验收：11 个页签、0 JS 错误、0 破图、每个模态都真的载出图
node tools\probe_web.js
\`\`\`
