# P0：天气状态机 + 波段选择（空场景 / 中波红外 / 雷达频段）

本文件记录 2026-10-29 完成的 P0 增量：一个天气状态向量同时驱动可见光、红外、雷达三个模态，
红外支持中波(MWIR 3–5 µm)与长波(LWIR 8–12 µm)双输出，雷达支持 X/Ku/K/Ka/W/W94 频段预设，
并新增可关闭地面的"空场景"与程序化四旋翼资产。

## 1. 为什么用"状态机"而不是每个模态各配一套天气

三模态必须共享同一个物理状态，否则同一帧里"下雨"对光学是浓雾、对雷达是晴天，数据集内部自相矛盾，
训练出的模型会学到与传感器无关的虚假相关性。约定：

```
weather = {cloud_cover, visibility_m, rain_mmh, wind_ms, air_temp_c, rh, sun_elev_deg, sea_state}
```

`weather.derive(state)` 一次性算出每个模态要用的派生量：太阳辐照度、天空亮温、地面湿润度、
光学消光系数、逐波段红外消光、逐波段雷达衰减。三个前向模型只读派生量，不再自己解释"天气"。

## 2. 预设

| 预设 | 云量 | 能见度 | 雨强 mm/h | 用途 |
|---|---|---|---|---|
| clear | 0.05 | 20 km | 0 | 晴空基准 |
| cloudy | 0.85 | 10 km | 0 | 阴天、低对比度 |
| rain | 0.95 | 4 km | 8 | 中雨 |
| fog | 0.60 | 0.8 km | 0 | 雾（光学几乎失效、红外衰减、雷达几乎无影响）|
| storm | 1.00 | 1.5 km | 32 | 暴雨 |

字段可被单帧覆盖（`weather.states[i]` 里写任意字段即覆盖预设）。帧级循环：`states[f % len(states)]`。

## 3. 公式与出处

| 量 | 公式 | 说明 |
|---|---|---|
| 太阳直射 | `G_dir = 1361·0.75^(m^0.678)·sin(el)`，`m=1/sin(el)` | 大气质量衰减的工程近似（Meinel 型）|
| 太阳散射 | `G_dif = 0.15·1361·sin(el)·(0.3+0.7·cloud)` | 云天散射占比随云量上升 |
| 总辐照 | `G = G_dir·(1-0.85·cloud^2.5) + G_dif` | 云对直射的遮挡 |
| 晴空亮温 | `T_sky = 0.0552·T_air^1.5·(1-0.25·rh)` | Swinbank(1963) 经验式，湿度修正 |
| 云天亮温 | `T_sky += (T_air-2 - T_sky)·cloud` | 云底向环境温度插值 |
| 光学消光 | `β = 3.912 / V_km` | Koschmieder 能见度关系 |
| 红外逐波段消光 | `τ_b = τ_b0·(1+0.4·rh)·(20/V_km)^0.3 + 0.02·R^0.8` dB/km | `τ_b0`: MWIR 0.10 / LWIR 0.06 / SWIR 0.15 |
| 雷达气体吸收 | 频段表常量（ITU-R P.676 量级）| 77 GHz 正落在 O₂ 吸收线上，0.40 dB/km |
| 雷达雨衰 | `γ = k·R^α` dB/km | ITU-R P.838-3 水平极化系数 |
| 地面湿润度 | `wetness = min(1, R/4)` | 湿地面：反照率降 25%、蒸发多一份对流散热 |

雷达频段表（`weather.RADAR_BANDS`）：

| 频段 | 载频 GHz | 默认方位/俯仰波束 | 气体 dB/km | 雨衰 k / α |
|---|---|---|---|---|
| X | 9.5 | 1.5° / 5.0° | 0.008 | 0.0101 / 1.276 |
| Ku | 15.0 | 1.0° / 4.0° | 0.015 | 0.0367 / 1.154 |
| K | 24.0 | 0.8° / 3.0° | 0.020 | 0.090 / 1.065 |
| Ka | 35.0 | 0.5° / 2.0° | 0.075 | 0.187 / 1.021 |
| W | 77.0 | 2.0° / 12.0° | 0.400 | 0.90 / 0.86 |
| W94 | 94.0 | 1.0° / 8.0° | 0.450 | 1.40 / 0.81 |

用法：`sensors.radar.band = "Ka"`，载频与波束宽自动取自预设；显式写 `fc_ghz` / `beamwidth_*` 则覆盖预设。
衰减在链路预算后按双程乘 `10^(-(γ_gas+γ_rain)·2d/10)`，`d` 为该波束命中点的距离。

## 5. 多波段输出

`ir.bands = ["mwir","lwir"]` 时，同一温度场渲染两次，目录加后缀：

```
images/ir_mwir/000000.png        16bit 原始计数（200–450 K 固定物理窗口）
images/ir_lwir/000000.png
images/ir_preview_mwir/*.png     8bit 预览
labels/ir_mwir/*.json            band 字段标明波段
annotations_ir_mwir_coco.json    每个波段一份 COCO
annotations_ir_lwir_coco.json
```

不写 `bands` 时保持旧行为（`images/ir`、`annotations_ir_coco.json`），下游脚本不受影响。

## 6. 空场景（air）要点

```json
{"ground": {"enabled": false},
 "objects": [{"shape": "obj", "model": "../assets/models/uav_demo.obj",
               "height": 0.19, "pos": [0,0,60], "vel": [4,0,0], "rcs_db": -12}],
 "weather": {"states": [{"preset":"clear"},{"preset":"cloudy"},{"preset":"rain"}]}}
```

- `shape` 必须写 `obj`，否则按 `box` 处理（这个坑踩过：模型路径对但形状字段缺省，得到的是个盒子）。
- `model` 相对 `scenes/` 解析，写 `../assets/...`。
- 目标在高空时红外背景就是天空亮温（约 280 K），预览会呈"灰天空 + 白目标"，这是自动增益的正常表现。

## 8. 已知限制（必须写进任何对外文档）

1. **短距场景里天气对雷达几乎无影响**：70 m 上 5 dB/km 的雨衰只有 0.0007 dB。要让雨衰体现出来，距离必须到公里级；
   这不是模型缺陷，是物理事实。演示"雨对雷达的影响"必须换长距场景。
2. **无人机 RCS 不确定性极大**（文献 −20…−5 dBsm，与姿态、旋翼转速、频段强相关）。示例里写死 −12 dBsm，标定前不可当真值。
3. **红外消光系数是工程近似**，不是逐线积分；要更高保真需接 HITRAN / lowtran（合法免费）。
4. **可见光后端的天气只是光照/浑浊度近似**，没有体积散射，雨丝、雾团不会出现在画面上。
5. **天空亮温**用 Swinbank 经验式，晴空约 280–290 K；真实晴空有效亮温可低到 240 K，需要时用 `preview_window_c` 手动设定窗口。
