# 雷达面元 RCS 标定

资产卡片的 RCS 是校验基准。这份文档记录用它对仿真器做校验时发现了什么。

## 一、没通过的校验

拿 11 个型号档案逐一比对，15 GHz，迎头到侧向，仿真给出的面元 RCS 与公开值差 −25 ~ +31 dB：

| 型号 | 仿真 | 参考 | 偏差 |
|---|---|---|---|
| DJI Mavic 3 | 0.00014 m² | 0.042 m² | −25.6 ~ −24.1 dB |
| DJI Mini 3 | 0.00033 m² | 0.015 m² | −19.2 ~ −16.1 dB |
| Matrice 350 | 0.0085 m² | 0.15 m² | −13.8 ~ −11.2 dB |
| M1A2 | 421 m² | 20 m² | +10.8 ~ +14.5 dB |
| F-15C | 714 m² | 25 m² | +11.8 ~ +15.9 dB |
| AH-64D | 548 m² | 6 m² | +13.8 ~ +19.9 dB |
| Su-27 | 2694 m² | 15 m² | +18.4 ~ +23.6 dB |
| F-16C | 1330 m² | 1.2 m² | +26.3 ~ +30.7 dB |
| MQ-9A | 1197 m² | 1.29 m² | +27.1 ~ +30.3 dB |
| J-10C | 2638 m² | 1.5 m² | +30.0 ~ +34.1 dB |

误差方向随目标尺寸翻转：小目标偏低，大目标偏高。这个符号规律本身指出了成因。

## 二、成因一：面元求和不是网格无关的

镜面项按面积平方标度（4πA²/λ²）。逐面元分别平方再相加，把一块板切成 n 块就损失 n 倍。

实测同一块 1 m² 平板：

| 面元数 | 逐面元求和 | 相干求和 |
|---|---|---|
| 1 | 19.6176 m² | 19.6176 m² |
| 4 | 4.9240 | 19.6176 |
| 16 | 1.2507 | 19.6176 |
| 64 | 0.3323 | 19.6176 |
| 256 | 0.1027 | 19.6176 |

逐面元求和从 19.6 掉到 0.10，差 192 倍。这意味着「模型多边形预算」是一个隐藏的雷达参数——同一个目标换个 decimate 设置，RCS 能差两个数量级。

这解释了误差的符号：Mavic 有 3500 个细面元所以偏低，F-16 的 1434 个面元里有 60 个大于 1 m² 所以偏高。

## 三、成因二：specular_scale_db = −20 dB 是补偿项

内核里有个 specular_scale_db，默认 −20 dB，注释写着「标定系统性偏乐观的平面镜面项」。

它确实是补偿项，但它补偿的是那些 bug。常数补偿无法应对变量（网格密度），所以只能让量级大致落在合理范围，无法真正标定。

## 四、正确的公式

相干求和必须先累加复场、再取模平方：

    sigma = (4π/λ²) · | Σ_i A_i (n_i · i) ρ_i exp(j k (i − r) · c_i) |²

已实现为 radar.coherent_po_sigma()，验证：

- 网格无关性：1 m² 平板切成 1 / 4 / 16 / 64 / 256 / 1024 / 4096 面元，结果全部 41.45 dBsm，差 < 1e-4 dB
- 绝对量级：0.3 × 0.3 m 平板 @ 10 GHz 给出 20.53 dBsm，解析值 20.53 dBsm，差 0.01 dB

## 五、换了正确公式，还是没有通过

把审计工具切到相干 PO 后，偏差反而扩大到 +28 ~ +58 dB（大目标）。

原因不是公式错，是平面面元 PO 本身预测不了复杂目标的绝对 RCS。参考手册 §3.1 的适用性表写得很清楚：PO 对规则形状 ±1.5–3 dB，而真实目标的主要散射机制是多次反射、边缘绕射、腔体回波——这些 PO 都不算。F-16 的 1.2 m² 里有大量来自进气道和座舱的腔体贡献，平面面元给不出。

补上粗糙度去相干因子后仍是 +30 dB 量级。这条路径走下去等于重写散射模型，不是标定。

## 六、结论

1. facet_sigma 的逐面元求和有网格依赖，是确定的缺陷，但它是检测链路当前使用的量。改动它会让 datasets/1102、datasets/yolo 的检出率数字全部失效，因此保持原状，缺陷记录在此。

2. radar.coherent_po_sigma() 是正确的 PO 原语，已验证网格无关且与解析式吻合，作为工具保留。它适用于规则形状（平板、角反射器、简单箱体），不适用于复杂目标。

3. 平面面元 RCS 不可作为复杂目标的绝对量级依据。这与「资产卡片里的 RCS 只作校验基准」的决策一致，但现在有了具体理由：不是保守，是方法边界。

4. 若检测任务需要可信的绝对 RCS，有两条路：
   - 用档案里的型号 RCS 作为检测方程的输入（rcs_db），放弃姿态起伏；
   - 保留面元计算但只取其相对起伏（姿态调制形状），绝对量级用档案值锚定。

   两者都是工程折衷，没有免费的正确答案。
