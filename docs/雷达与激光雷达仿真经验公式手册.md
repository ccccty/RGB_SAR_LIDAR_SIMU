## 1. 面片级 RCS 聚合：相干还是非相干？

### 1.1 单面片的 PO 复数散射场

对第 i 个三角面片（面积 A_i，法向与视线夹角 theta_i）：

$$
\underline{E}_i=\sqrt{\sigma_i}\;\exp\!\big(j\,2k\,\hat{\mathbf r}\cdot\mathbf r_i\big)\;\exp\!\big(j\varphi_i\big),
\qquad k=\frac{2\pi}{\lambda},\quad
\sigma_i=\frac{4\pi A_i^2\cos^2\theta_i}{\lambda^2}\,\rho_i^2\,|\Gamma(\theta_i)|^2
$$

- r_i：面片中心位置（m）；r_hat：雷达到目标单位矢量（单站）
- 2k(r_hat·r_i)：**双程**相位，这是相干叠加的全部意义
- rho_i^2：粗糙度相干因子（§1.3）；|Gamma|^2：菲涅尔反射系数模方（金属≈1，介质≈0.1–0.4）

**注意**：4 pi A^2 cos^2(theta)/lambda^2 只在**镜面方向附近**成立，角向宽度约 lambda/L。拿它当宽角规律是错的，正确形式见 §1.6。

### 1.2 三种叠加方式

相干（场相加后取模方）：

$$
\sigma_{\text{coh}}=\Big|\sum_i \sqrt{\sigma_i}\,e^{j2k\hat{\mathbf r}\cdot\mathbf r_i}\Big|^2
$$

非相干（功率相加）：

$$
\sigma_{\text{inc}}=\sum_i \sigma_i
$$

混合式（绝大多数真实目标应走这条）：

$$
\sigma_{\text{mix}}
=\underbrace{\Big|\sum_i \sqrt{\sigma_i}\,\rho_i\,e^{j2k\hat{\mathbf r}\cdot\mathbf r_i}\Big|^2}_{\text{镜面 / 确定性分量}}
+\underbrace{\sum_i \sigma_i\,(1-\rho_i^2)}_{\text{漫射分量}}
$$

### 1.3 判定准则（三条同时满足才允许相干）

**(A) 相位采样判据（数值收敛）**：面片内双程相位变化 ≤ pi/2

$$
\boxed{\ L\le\frac{\lambda}{8\sin\theta}\ }\quad(\text{面片最大边长})
$$

不满足时相干求和给出的是**网格伪影**（结果随网格旋转闪烁），不是物理。表中已给出数值——cm 级面片全部违反。

**(B) 表面粗糙度（Rayleigh / Ament）**：面片内高度起伏 RMS 记为 sigma_h

$$
\boxed{\ \rho^2=\exp\!\Big[-\Big(\frac{4\pi\sigma_h\cos\theta}{\lambda}\Big)^2\Big]\ }
$$

| 条件 | 判据 | 处理 |
|---|---|---|
| 光滑（镜面） | sigma_h < lambda/(32 cos theta)，即 rho^2 > 0.85 | 相干叠加 |
| 过渡 | lambda/(32cos) < sigma_h < lambda/(8cos) | 用 sigma_mix |
| 粗糙（漫射） | sigma_h > lambda/(8 cos theta)，rho^2 < 0.09 | 非相干功率叠加 |

（Ament 粗糙度因子；见 Ulaby & Dobson, Handbook of Radar Scattering Statistics for Terrain, 1989；Long, Radar Reflectivity of Land and Sea, 3rd ed., 2001。）

**(C) 分辨单元判据（决定"可观测"的是什么）**：

$$
\Delta R=\frac{c}{2B},\qquad \Delta v=\frac{\lambda}{2T_{\text{CPI}}},\qquad \Delta\theta\approx\frac{\lambda}{D}
$$

- 全部散射中心落在同一 (ΔR, Δv, Δtheta) 单元内 → **物理上就是相干叠加**，输出确定性复数，幅度 = sqrt(sigma_coh)。
- 目标尺寸 >> ΔR → 每个距离单元各自相干求和，单元间功率相加。
- 单元内包含大量**未分辨、相位随机**的子结构（N_eff >> 10，相位在 [0, 2pi) 均匀）→ 先功率叠加得平均 RCS，再叠加起伏（§2）。此时 E[sigma_coh] = Σ sigma_i = sigma_inc，且 sigma_coh 服从指数分布（方差 = 均值平方）。

### 1.4 现有做法在什么条件下高估 / 低估

| 做法 | 结果 | 偏差 | 触发条件 |
|---|---|---|---|
| 所有面片相位置 0、幅度相加 | (Σ√sigma_i)^2 | 高估最多 N 倍（10log10 N dB） | 任何有曲率的目标 |
| 粗糙面上做相干叠加而网格不收敛 | 随机 | ±10log10 N dB 双向错 | sigma_h > lambda/8 或 L > lambda/(8 sin) |
| 平板/二面角却用功率叠加 | Σ sigma_i | **低估 N 倍** | 镜面反射主导（机腹、角反射器） |
| 用 cos^2(theta) 当全角域规律 | 大角度偏高 10–30 dB | 高估 | theta > lambda/L 之外 |
| 忽略遮挡与二次散射 | 阴影区仍有回波 | 高估 | 掠射、腔体（进气道） |
| 忽略边缘绕射 | — | **低估**细小部件（桨叶、天线、起落架） | 部件尺寸 ~ lambda |
| 面片 < lambda 仍用 PO | 相位与幅度皆错 | 随机 | 高频段细分网格 |

> 多旋翼无人机：机身/机臂是"少数大面片 + 大量小部件"。正确做法是 **mix 式**：机身镜面分量相干，其余功率叠加，最后整体乘 §2 的起伏。

### 1.5 推荐实现（可直接翻译成 Python）

```python
import numpy as np

def facet_sigma(A, cos_t, lam, rho2=1.0, gamma2=1.0):
    """单面片 PO RCS (m^2)。A: 面积 m^2; cos_t: cos(入射角)"""
    return 4*np.pi*A**2*cos_t**2/lam**2 * rho2 * gamma2

def roughness_rho2(sigma_h, cos_t, lam):
    """Ament 相干因子, sigma_h 为面片内高度 RMS (m)"""
    return np.exp(-(4*np.pi*sigma_h*cos_t/lam)**2)

def aggregate(facets, lam, k_hat, mode="auto", sigma_h=0.0):
    """
    facets: [{'pos':(3,), 'A':, 'cos_t':, 'gamma2':}, ...]
    k_hat : 单位视线矢量（雷达到目标）
    mode  : 'coh' | 'inc' | 'auto'
    """
    A   = np.array([f['A'] for f in facets])
    ct  = np.array([f['cos_t'] for f in facets])
    g2  = np.array([f['gamma2'] for f in facets])
    pos = np.array([f['pos'] for f in facets])
    s   = 4*np.pi*A**2*ct**2/lam**2 * g2
    ph  = 2*(2*np.pi/lam)*(pos @ k_hat)

    if mode == "inc":
        return s.sum()

    if mode == "auto":
        L     = np.sqrt(A)                     # 等效边长
        sin_t = np.sqrt(np.clip(1-ct**2, 0, 1))
        ok_A  = np.all(L <= lam/(8*np.maximum(sin_t, 1e-6)))
        rho2  = roughness_rho2(sigma_h, ct, lam)
        ok_B  = np.all(rho2 > 0.85)
        if ok_A and ok_B:
            return abs(np.sum(np.sqrt(s)*(np.exp(1j*ph))))**2
        spec = abs(np.sum(np.sqrt(s*rho2)*np.exp(1j*ph)))**2
        return spec + np.sum(s*(1-rho2))       # 混合式

    return abs(np.sum(np.sqrt(s)*np.exp(1j*ph)))**2
```

### 1.6 平板 PO 的角向修正（必须加，否则大角度全错）

边长 Lx × Ly 的矩形平板绕 x 轴倾斜 theta：

$$
\sigma(\theta)=\frac{4\pi A^2\cos^2\theta}{\lambda^2}
\Big[\frac{\sin(kL_x\sin\theta)}{kL_x\sin\theta}\Big]^2
\Big[\frac{\sin(kL_y\sin\theta\sin\phi)}{kL_y\sin\theta\sin\phi}\Big]^2
$$

主瓣 3 dB 宽 ≈ 0.886·lambda/L，第一零点 theta_1 = lambda/(2L)。三角面片用等效 L = sqrt(4A/pi)。**面片内部不再细分时，这条 sinc^2 就是"面片图案"，是逐面片 PO 唯一正确的角向处理。**

## 2. Swerling 起伏模型

### 2.1 统计定义与生成

设平均 RCS 为 sigma_bar，g = sigma / sigma_bar，U 为 (0,1) 均匀随机数：

| 模型 | RCS 的 PDF | 起伏速率 | 生成式 |
|---|---|---|---|
| Swerling 0 | 确定性 sigma = sigma_bar | — | 常数 |
| Swerling I | p(sigma) = (1/sigma_bar)·exp(-sigma/sigma_bar) | **扫描间**（一个 CPI 内恒定） | sigma = -sigma_bar·ln U，每 CPI 抽一次 |
| Swerling II | 同上 | **脉冲间** | sigma_i = -sigma_bar·ln U_i，每脉冲抽 |
| Swerling III | p(sigma) = (4 sigma / sigma_bar^2)·exp(-2 sigma/sigma_bar) | 扫描间 | sigma = -(sigma_bar/2)(ln U1 + ln U2)，每 CPI 一次 |
| Swerling IV | 同上 | 脉冲间 | 每脉冲一次 |
| Swerling k（推广） | sigma ~ (sigma_bar/2k)·chi2(2k) | 可快可慢 | rng.gamma(k, scale=sigma_bar/k) |

（Swerling, IRE Trans. IT-6, 1960；Skolnik, Radar Handbook 3rd ed. Ch.2；Richards, Principles of Modern Radar Ch.16。）

### 2.2 生成器（注入复数幅度，而不是功率）

```python
import numpy as np

def swerling_power(rng, sigma_bar, case, n):
    """返回每个脉冲的目标平均功率（长度 n）"""
    if case == 0: return np.full(n, sigma_bar)
    if case == 1: return np.full(n, -sigma_bar*np.log(rng.random()))
    if case == 2: return -sigma_bar*np.log(rng.random(n))
    if case == 3:
        g = -0.5*(np.log(rng.random())+np.log(rng.random()))
        return np.full(n, sigma_bar*g)
    if case == 4:
        g = -0.5*(np.log(rng.random(n))+np.log(rng.random(n)))
        return sigma_bar*g
    raise ValueError(case)

def target_echo(rng, sigma_p):
    """复数回波幅度 a，E|a|^2 = sigma_p"""
    g = (rng.standard_normal(len(sigma_p))
         + 1j*rng.standard_normal(len(sigma_p)))/np.sqrt(2)
    return np.sqrt(sigma_p)*g
```

**相干体制的关键点（几乎所有开源仿真器都错在这里）**：
- FMCW 距离-多普勒 FFT 是**相干积分**。一个 CPI 内每个 chirp 的复幅度必须是**同一个** a（只差多普勒相位斜坡 exp(j2 pi f_d t)），否则 FFT 后能量散开、多普勒峰消失。
- 因此：**Swerling I/III 用在 CPI 之间；Swerling II/IV 只能用于"CPI 内相位已去相关"**（频率捷变、CPI 极长、或桨叶这类高速旋转部件）。
- 去相关时间：T_decorr ≈ lambda / (2 v_rms)，v_rms 为散射中心径向速度 RMS。机体取 1–3 m/s；桨叶取叶尖速度 80–120 m/s。
  X 波段桨叶：0.0316/(2×100) = 0.16 ms；94 GHz：16 µs → **桨叶回波必须按快起伏处理，并且带微多普勒**。

### 2.3 无人机该用哪个

**默认：Swerling I**（chi2，2 自由度），逐扫描更新，sigma_bar 取 §1 的 PO 平均值。

1. 多旋翼 = 十多个尺度相近的散射体 + 无主导散射体 → 指数分布（Swerling I/II）。
2. 若机身平板在某些姿态给出比其余散射体高 > 6 dB 的镜面闪烁 → **Swerling III**（一个主导 + 多个小散射体）。
3. 实测小型无人机 RCS 常重尾；若训练集强调"漏检"，用 **Swerling k，k = 0.5–1** 或 **K 分布（形状参数 0.5–2）**。
4. 姿态快速变化（悬停抖动 ±5°）时，sigma_bar 本身应随姿态变化（用 PO 角向曲线），而不是常数 sigma_bar + 起伏。

## 3. 检测与虚警

### 3.1 门限 ↔ 虚警率（精确闭式，可逆）

平方律检波、噪声功率归一化为 1、N 个独立脉冲非相干积累：

$$
\boxed{\ P_{fa}=e^{-V_T}\sum_{n=0}^{N-1}\frac{V_T^{\,n}}{n!}
=\frac{\Gamma(N,V_T)}{\Gamma(N)}=Q_{\chi^2}(2V_T;\,2N)\ }
$$

```python
from scipy.special import gammaincc, gammaincinv
V_T = gammaincinv(N, 1.0 - Pfa)     # 线性门限（噪声功率 = 1）
Pfa = gammaincc(N, V_T)
# 等价：V_T = 0.5*scipy.stats.chi2.ppf(1-Pfa, 2*N)
```

N=1 时 V_T = -ln(Pfa)。**你们现在的 det_snr_db 就是 10*log10(V_T)。**

| N | Pfa=1e-2 | 1e-3 | 1e-4 | 1e-6 | 1e-8 |
|---|---|---|---|---|---|
| 1  | 6.63 | 8.39 | 9.64 | 11.40 | 12.65 |
| 4  | 10.02 | 11.16 | 12.02 | 13.29 | 14.25 |
| 16 | 14.27 | 14.95 | 15.48 | 16.30 | 16.93 |
| 64 | 19.25 | 19.62 | 19.92 | 20.39 | 20.77 |

（dB，相对单脉冲噪声功率。**[实测校验]**）

### 3.2 检测概率：Marcum Q 及可用近似

非起伏目标（Swerling 0）、N 脉冲、单脉冲 SNR = S：

$$
P_d=Q_N\big(\sqrt{2NS},\ \sqrt{2V_T}\big),\qquad
Q_M(a,b)=\int_b^\infty x\Big(\frac{x}{a}\Big)^{M-1}e^{-(a^2+x^2)/2}I_{M-1}(ax)\,dx
$$

最稳实现：scipy.stats.ncx2.sf(2*V_T, 2*N, 2*N*S)（非中心 chi2 尾概率，与 Marcum Q 完全等价）。

近似式（a >> 1，误差 O(1/a)，适合快速反解）：Q_M(a,b) ≈ Q(b−a)，Q(x) = erfc(x/√2)/2。

**工程反解（Albersheim 方程）**：

$$
\mathrm{SNR_{dB}}=-5\log_{10}N+\Big[6.2+\frac{4.54}{\sqrt{N+0.44}}\Big]\log_{10}\big(A+0.12AB+1.7B\big)
$$
$$
A=\ln\frac{0.62}{P_{fa}},\qquad B=\ln\frac{P_d}{1-P_d}
$$

适用 1e-7 ≤ Pfa ≤ 1e-3、0.1 ≤ Pd ≤ 0.9、1 ≤ N ≤ 8096，误差 < 0.2 dB。
校验：Pfa=1e-6, Pd=0.9, N=1 → 13.11 dB（精确 13.18 dB）✓（Albersheim, Proc. IEEE 69(7), 1981。）

**Swerling 情形的精确式（直接数值积分，别背近似）**：

$$
P_d=\int_0^\infty p(g)\,Q_N\big(\sqrt{2NSg},\sqrt{2V_T}\big)\,dg
=\int_0^\infty p(g)\,\frac{\Gamma(N,\ V_T/(1+Sg))}{\Gamma(N)}\,dg
$$

- Sw-I/II：p(g) = exp(-g)；Sw-III/IV：p(g) = 4g·exp(-2g)
- II/IV 是脉冲间独立，严格式需对每个 g_i 求 N 重积分 → 实践用 MC（附录 A）

\boxed{\ \alpha=N_r\Big(P_{fa}^{-1/N_r}-1\Big)\ },\qquad V_T=\alpha\cdot\frac1{N_r}\sum_{i\in\text{ref}}z_i
$$

## 4. 地 / 海杂波经验模型

### 4.1 海杂波：NRL 模型（首选，已对齐 MATLAB 官方算例到 0.01 dB）

Gregers-Hansen & Mittal, NRL/MR/5310-12-9346, 2012；IEEE TAES 48(4), 2012。
适用：f = 0.5–35 GHz，擦地角 psi = 0.1°–60°，海况 SS = 0–6，与实测绝对偏差约 2.2–2.3 dB。

$$
\boxed{
\sigma^0_{\rm dB}=C_1+C_2\log_{10}(\sin\psi)
+\frac{(27.5+C_3\,\psi)\log_{10}f}{1+0.95\,\psi}
+C_4\,(SS+1)^{\frac{1}{2+0.085\psi+0.033\,SS}}
+C_5\,\psi^2
}
$$

| V | −50.796 | 25.93 | 0.7093 | 21.588 | 0.00211 |

psi 用**度**，f 用 GHz，sigma^0 为 dB。

### 4.2 海杂波：GIT 模型（Horst, Dyer & Tuley, 1978）

结构：HH/VV 分开、按频段（≤3 / 3–12 / >12 GHz）三段，自变量 lambda、psi、风速 Vw、风向、波高 h_av。
>12 GHz 段（覆盖 K/Ka/W，可直接用）：

$$
\phi_\sigma=\frac{(14.4\lambda+5.5)\,\psi\,h_{av}}{\lambda+0.015},\quad
A_i=\frac{\phi_\sigma^4}{1+\phi_\sigma^4},\quad
A_u=\exp\big(0.25|\cos\varphi_w|(1-2.8\sin\psi\,\lambda^{-0.33})\big),
$$
$$
q_w=1.93\lambda^{-0.04},\quad
A_w=\Big(\frac{1.94V_w}{1+V_w/15.4}\Big)^{q_w},
$$
$$
\boxed{\ \sigma^0_{HH}=10\log_{10}\!\big(5.78\times10^{-6}\,\psi^{0.547}A_iA_uA_w\big)\ }
$$
$$
\sigma^0_{VV}=\sigma^0_{HH}-1.38\ln h_{av}+3.43\ln\lambda+1.31\ln(\psi+\epsilon)+18.55
$$

psi 用**弧度**，lambda 用 m，h_av = 4.52e-3·Vw^2.5 (m)，Vw = 2.15·SS^1.04 (m/s)，phi_w 为风向与视线夹角，sigma^0 为 dB。
参考实现：GTI_SigmaSea.m（§8 链接）。

> 工程建议：**X/Ku/K/Ka 用 NRL**（有官方算例可对齐）；**W 段**无公认标定，用 NRL 外推并明确标注"外推"更诚实。

### 4.3 地杂波：常数 gamma 模型

$$
\boxed{\ \sigma^0=\gamma\sin\psi\ }\qquad
\sigma^0_{\rm dB}=\gamma_{\rm dB}+10\log_{10}(\sin\psi)
$$

适用 psi 大于临界角（通常 5°–10°）。gamma_dB 典型值（X 波段、中值、全风向平均）：

| 地表 | gamma (dB) | 备注 |
|---|---|---|
| 平坦沙漠 / 盐碱地 | −40 … −35 | 最"干净" |
| 起伏荒漠、稀疏灌木 | −30 … −25 | |
| 农田（裸露、翻耕） | −28 … −22 | 湿度大取高值 |
| 草地 / 牧场 | −30 … −24 | |
| 农作物（高秆、成熟） | −20 … −15 | 随风摆动，谱宽大 |
| 森林（阔叶、有叶） | −20 … −14 | 体散射为主 |
| 森林（落叶 / 冬季） | −26 … −20 | |
| 城市 / 工业区 | −12 … −5 | 强镜面、重尾 |
| 积雪覆盖 | −35 … −30 | |
| 海冰 | −25 … −20 | |

（Nathanson, Radar Design Principles, 2nd ed., 1991, Ch.7；Long；Ulaby & Dobson 1989。）

**频率外推**（L→X 约 +3…+5 dB）：gamma_dB(f) ≈ gamma_dB(f0) + (4±2)·log10(f/f0)。

**低擦地角修正**（psi < psi_c 必须加，否则严重高估）：psi_c ≈ arcsin(lambda/(4 pi sigma_h))；psi ≥ psi_c 时 sigma^0_dB = gamma_dB + 10log10(sin psi)；psi < psi_c 时再加 k_psi·log10(psi/psi_c)，k_psi ≈ 1.5–2（平坦地表取 2），sigma_h 为地表高度 RMS。

### 4.4 雨杂波（体积散射，仿真里最常被漏掉）

$$
\eta=\frac{\pi^5|K|^2 Z}{\lambda^4}\ [\mathrm{m^2/m^3}],\qquad
Z=200\,R^{1.6}\ [\mathrm{mm^6/m^3}],\qquad |K|^2=0.93
$$
$$
\sigma_{\rm rain}=\eta\,V_c,\qquad V_c\approx R^2\,\Omega\,\frac{\Delta R}{2}
$$

**量级警告**：X 波段、R_rain = 25 mm/h、3° 波束、ΔR = 7.5 m、距离 1 km：
eta ≈ 9.8e-6 m²/m³，V_c ≈ 1.6e4 m³ → sigma_rain ≈ 0.16 m² = −8 dBsm。
**这比一架小型无人机的 RCS（−20…−10 dBsm）还大**——不建模雨杂波，检测训练完全失真。
（Marshall & Palmer 1948；Gunn & East 1954；Battan, Radar Observation of the Atmosphere。）

## 6. 激光雷达（脉冲飞行时间 / 直接探测）

### 6.1 硬目标激光雷达方程（Lambertian 扩展目标）

$$
\boxed{\ P_r=P_t\,\eta_t\eta_r\,\frac{\rho}{\pi}\,\frac{A_r\cos\theta}{R^2}\;e^{-2\alpha R}\ }
$$

- P_t 发射功率 (W)，rho 漫反射率（0.05–0.9），A_r = pi·D_r²/4 接收面积 (m²)
- theta 入射角，alpha 消光系数 (m⁻¹)，R 距离 (m)
- 与雷达方程对比：**R⁻²**（不是 R⁻⁴），且无 lambda²、无 (4pi)³ 分母

光子计数形式：

$$
\boxed{\ N_{pe}=\frac{P_t\,\tau\,\lambda}{hc}\,\eta_t\eta_r\eta_d\,
\frac{\rho A_r\cos\theta}{\pi R^2}\,e^{-2\alpha R}+N_{bg}\ }
$$
$$
N_{bg}=\eta_d\,L_\lambda\,\Omega_{\rm FOV}\,A_r\,\Delta\lambda\,\tau
$$

L_lambda 背景辐亮度 (W·m⁻²·sr⁻¹·nm⁻¹)，Omega_FOV 接收立体角，Delta_lambda 滤光片带宽，tau 门宽 (s)。

### 6.2 大气消光：Kim / Kruse 模型

$$
\boxed{\ \alpha=\frac{3.912}{V}\Big(\frac{\lambda}{0.55\,\mu\mathrm m}\Big)^{-q}\quad[\mathrm{km^{-1}}]\ }
$$

V = 能见度 (km)，lambda 单位 µm。

| 能见度 | Kim q | Kruse q |
|---|---|---|
| V > 50 km | 1.6 | 1.6 |
| 6 < V < 50 km | 1.3 | 1.3 |
| 1 < V < 6 km | 0.16V + 0.34 | 0.585·V^(1/3) |
| 0.5 < V < 1 km | V − 0.5 | 0.585·V^(1/3) |
| V < 0.5 km | 0 | 0.585·V^(1/3) |

（Kim, McArthur & Korevaar, Proc. SPIE 4214, 2001；Kruse et al., Elements of Infrared Technology, 1962。）

**[实测校验] 数值**：

| 天气 | V | alpha_905 (km⁻¹) | alpha_1550 (km⁻¹) | 100 m 透过率 @1550 |
|---|---|---|---|---|
| 浓雾 | 50 m | 30.5 | 23.3 | 0.10 |
| 雾 | 200 m | 10.7 | 8.2 | 0.44 |
| 轻雾 | 1 km | 3.05 | 2.33 | 0.79 |
| 霾 | 5 km | 0.87 | 0.75 | 0.93 |
| 晴朗 | 20 km | 0.20 | 0.20 | 0.96 |

### 6.3 散斑（speckle）统计

完全发育散斑（sigma_h >> lambda）：强度服从**负指数分布**，p(I) = (1/I_bar)·exp(-I/I_bar)，sigma_I/I_bar = 1。
若接收孔径平均了 M 个独立散斑单元：

$$
p(I)=\frac{M^M}{\Gamma(M)}\frac{I^{M-1}}{\bar I^M}e^{-MI/\bar I},\qquad
\frac{\sigma_I}{\bar I}=\frac1{\sqrt M}
$$

散斑相关尺寸 d_coh ≈ lambda·R/d_t（d_t 为照明光斑直径），于是

$$
\boxed{\ M\approx\frac{\pi}{4}\Big(\frac{D_r}{d_{\rm coh}}\Big)^2
=\frac{\pi}{4}\Big(\frac{D_r\,d_t}{\lambda R}\Big)^2\ }
$$

**[实测校验]**：lambda=905 nm、d_t=5 cm、R=50 m、D_r=25 mm → d_coh=0.905 mm、M≈600、对比度 4%；
lambda=1550 nm、d_t=5 cm、R=200 m、D_r=50 mm → M≈51、对比度 14%。

**实现**：每次回波强度乘一个 Gamma(M, 1/M) 随机数（均值 1）。M=1 就是"单散斑"，会出现整帧丢失——大量深度学习 lidar 仿真漏掉这一步，点云因此过于"干净"。（Goodman, Statistical Optics, 2nd ed., 2015, Ch.2。）

### 6.4 雨 / 雪消光（激光）

**雨**：雨滴半径 >> lambda，消光截面 ≈ 2× 几何截面（消光佯谬），对 Marshall-Palmer 谱积分：

$$
\boxed{\ \alpha_{\rm rain}\approx0.365\,R^{0.63}\ \ [\mathrm{km^{-1}}],\quad R\ [\mathrm{mm/h}]\ }
$$

推导：alpha = 2∫(pi D²/4)N(D)dD，N(D)=8000·exp(-Lambda D)，Lambda=4.1·R^(-0.21) → alpha = pi·N0/Lambda³。
数值：R=1 → 0.36 km⁻¹（1.6 dB/km）；10 → 1.55（6.7 dB/km）；50 → 4.3（18.5 dB/km）。实测常在此值的 0.5–1 倍。

**雪**：雪花 0.5–5 mm >> lambda，消光近似**与波长无关**（q ≈ 0）：alpha_snow ≈ 3.912/V_snow km⁻¹，或按等效水厚 S (mm/h) 取 alpha_snow ≈ (0.5–2)·S dB/km（干雪低、湿雪高）。
**905 nm 与 1550 nm 在雪中几乎一样差**——"1550 nm 抗恶劣天气更好"只对雾成立。

### 6.5 测距精度（写进误差模型）

$$
\sigma_R\approx\frac{c}{2B\sqrt{2\,\mathrm{SNR}}}
$$

B=20 MHz → 0.53 m @20 dB；150 MHz → 71 mm；1 GHz → 11 mm。

## 7. 现状中会误导检测训练的做法（按危害排序）

| # | 现状 | 后果 | 修正 |
|---|---|---|---|
| 1 | **固定 det_snr_db 门限，不做 CFAR** | 虚警率随距离/噪声/杂波漂移几个数量级；网络学到"现实中不存在的固定门限"，换场景即崩 | 改 2D CA/OS-CFAR（§3.3）；若必须固定，至少标定 Pfa 并加随机化 |
| 2 | **逐面片 PO 相位处理不当**（全零相位相加 / 粗糙面仍相干 / 平板却功率相加） | RCS 整体偏 10log10(N) dB；角度闪烁完全错；镜面闪烁丢失 | 按 §1.3 判据分支；cm 级网格默认走 §1.2 的 mix 式 |
| 3 | **无 Swerling 起伏**（或只在最后乘一个随机数） | Pd 曲线整体偏移 8–13 dB；检测退化为确定性映射 | 按 §2.2 注入复数幅度；起伏放在 CPI 层，相干积分内部不要加随机相位 |
| 4 | **无地/海/雨杂波** | 虚警率≈0，无虚警航迹，CFAR/MTI 模块从未被训练到 | 至少加：地杂波 gamma 模型 + 海杂波 NRL + 雨体积杂波 |
| 5 | **MTI 用 abs(v_r) 硬门限** | 这不是 MTI。真实 MTI 有凹陷宽度、盲速、杂波谱泄漏；硬门限 = 无限深理想凹陷，虚警被系统性低估 | 用 H(f)=1−exp(−j2pi fT) 型响应；杂波谱宽 sigma_f = 2·sigma_v/lambda（植被 0.3 m/s）；盲速 v_b = n·lambda/(2T) |
| 6 | **处理增益直接写 10log10(n_chirps)** | 对起伏目标高估增益（Sw-I 在 N=16 比 Sw-0 多需 8.5 dB）；非相干积累同样高估 | 用 §2.4 表；或直接对复数做 FFT，让增益自然出现 |
| 7 | **噪声带宽 B 取错** | SNR 偏 1–2 dB（Hann 窗 ENBW=1.5，即 +1.76 dB） | B_eff = B·ENBW_window，或按 FFT 分辨率×窗因子算 |
| 8 | **大气只做常数损耗** | 距离依赖丢失；W 段 1 km 就有 0.4–14 dB | L(R) = L0·10^(2·gamma·R/10)，逐距离门乘 |
| 9 | **理想点扩散函数**（无窗、无旁瓣） | 强目标旁瓣泄漏、遮蔽弱小目标的现象学丢失 | 加窗（Hann/Taylor），保留旁瓣 |
| 10 | **只存功率立方体** | 无法相干处理、无法复现多普勒相位、无法注入微多普勒 | 存复数 I/Q；功率图由模方派生 |
| 11 | **无人机按点目标建模** | 丢失桨叶微多普勒、姿态闪烁、极化差异 | 机身（Swerling I）+ 桨叶（多个微动散射点，v_tip≈100 m/s） |
| 12 | **激光雷达无散斑、无雾衰减、无背景光** | 点云过于干净、远距离点密度不真实、学不到"低 SNR 丢点" | 加 Gamma 散斑、alpha(V) 衰减、N_bg 泊松噪声 |

**优先级**：先做 #1 + #3 + #4——这三项决定检测问题的**难度与统计特性**；#2 决定 RCS 的**绝对标度**；#5–#12 决定**细节真实度**。
