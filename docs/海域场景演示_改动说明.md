# 在线展示页新增海域场景（2026-11-08）

本次在 `https://ccccty.github.io/RGB_SAR_LIDAR_SIMU/` 的空域精选之外新增一处**海域场景演示**：
开阔海面 + 舰船目标，接入现有场景卡片体系，原有空域演示的主视觉、原理区、雷达深读区与卡片全部保持不变。

## 二、舰船目标的尺寸与可见性设定

尺寸是**按画面占比反推的设计值**，不是模型原生尺寸：

- 模型：`assets/models/军舰/战列舰.obj`，`scale = 0.22`，对应约 38 m 的设计舰长。
  选它而不是导弹艇，是因为俯视轮廓里舰艏、炮塔、上层建筑的层次更明确。
- 几何：相机高度约 1.86 km，正俯视，画幅覆盖 260×195 m；目标居中略偏左（`uv = [0.45, 0.52]`）。
- **实测标注框 243.1 × 112.4 px**（读自 `out/demo_sea_surface/labels/optical/000000.json`）：

| 指标 | 数值 |
|---|---|
| 占画幅宽 | 19.0 % |
| 占画幅高 | 11.7 % |
| 占画幅面积 | 2.22 % |

设定取向说明：

1. **不占过大画面**——面积仅 2.2 %，海面波浪仍是画面主体；对照现有空域演示中约 20 % 宽的战机，舰船不更大。
2. **清晰可辨**——243 px 宽的舰体在卡片大图里仍有约 85 px，舰艏、双炮塔与甲板构件可辨；
   灰色舰体与蓝色海面有稳定的亮度/色度差，红外预览里是轮廓完整的冷色剪影，雷达 RD 上目标峰与零速线分离清楚。
3. **没有再往小做**——再缩小会让炮塔细节掉到 10 px 以下，缩略条（420 px 宽缩略图）里将只剩一个点，
   与"清晰可辨"冲突。19 % 宽是这两条约束的折中。

### 为什么改了渲染内核的两处路径解析

入库的场景配置必须使用相对路径。排查中发现两条既有路径规则不一致：
`optical.sky_image` 与 `ir.background_image` 按场景文件目录解析，而 `ground.backdrop` 直接按进程 cwd 判断；
同时 `load_config()` 会把 `_render_cfg.json` 里由 `dataset._render_config` 写入的原始场景目录覆盖掉。
结果是：用绝对路径调试时海面正常，改成相对路径后底板被静默跳过，画面退化成一片灰蓝平场。
两处修改都只对相对路径生效，绝对路径配置的行为逐字不变，因此对已有演示无影响。

## 五、复现命令

```powershell
set PYTHONPATH=%CD%
env\Scripts\python.exe -m simkit gen -c scenes\demo_sea_surface.json -o out\demo_sea_surface -n 4 -s optical,ir,radar,lidar --seed 7
env\Scripts\python.exe tools\export_scene_web.py --scene demo_sea_surface ^
  --title "开阔海面 · 中小型舰船" --cls ship --aspect "4:3" --domain "air + sea" ^
  --frames 0,1,2,3 --hero-mod optical --hero-frame 1 ^
  --caption "开阔蓝色海面上的一艘中小型舰船，俯视轮廓能看清舰体与上层建筑，目标只占画面一小部分。" ^
  --note "4 帧 · 雷达 1.86 km · 舰船 243x112 px（占宽 19%、面积 2.2%）· 海面俯视"
```

导出工具按 id 替换而非追加，重复执行不会生成重复条目。
