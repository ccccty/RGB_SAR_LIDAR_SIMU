# simkit 离线部署手册（断网环境）

目标：把 simkit 交付到**完全没有互联网、没有 MATLAB、没有许可证服务器**的机器上，
复制即用，跑出自检与数据集。

本手册所有命令都是 Windows PowerShell 形式，可整段复制执行。命令中的路径请按实际盘符替换。

---

## 0. 结论先行

| 问题 | 答案 |
| --- | --- |
| 需要联网吗？ | 不需要。simkit 全部代码只调用本机进程（`subprocess` 启 Blender），没有任何 HTTP/socket 调用 |
| 需要 MATLAB 吗？ | **不需要**，一行都不需要 |
| 需要许可证服务器/激活吗？ | 不需要。Python（PSF 许可）+ numpy（BSD）都是自由软件；Blender 为 GPL 便携版，解压即用 |
| 需要装 Python 吗？ | 需要一份 **CPython 3.13 x64**，但**不需要管理员权限安装**——用便携/整目录复制即可 |
| 依赖有几个？ | **只有 numpy**，且已 vendored 在 `env\Lib\site-packages\numpy` |
| 需要编译器/GPU/CUDA 吗？ | 都不需要。纯 numpy CPU 代码，无 C 扩展需现场编译 |
| 交付体积 | 约 330 MB（含 Blender zip）；不含 Blender 约 75 MB |

**唯一的坑**：`env\` 是 venv，**不是**独立 Python 发行版，单独拷贝会启动失败。
第 3 节给出两种已验证的解决办法。

## 1. 交付物清单

以交付根目录 `D:\simkit_delivery\` 为例（**建议全 ASCII 路径**，中文路径能跑但少数工具链会踩坑）：

| 路径 | 内容 | 体积 | 必要性 |
| --- | --- | --- | --- |
| `simkit\` | 15 个 .py 源文件（核心） | 约 0.2 MB | **必须** |
| `scenes\` | `demo_ir.json` / `demo_all.json` / `demo_optical.json` | 约 2 KB | **必须**（自检要用 demo_ir） |

## 2. 整体拷贝目录

### 2.1 复制（推荐 robocopy，带重试、跳过缓存与产物）

```powershell
$src = '<项目根>'
$dst = 'D:\simkit_delivery'

robocopy $src $dst /E /XD out __pycache__ .git /XF *.pyc /R:1 /W:1 /NFL /NDL /NP
```

`robocopy` 的退出码 0–7 都算成功（8 及以上才是失败），所以 `$LASTEXITCODE` 为 1 时不用慌。

### 2.2 核对文件数

```powershell
$dst = 'D:\simkit_delivery'
"py 源文件: " + (Get-ChildItem "$dst\simkit" -Filter *.py).Count + " 个（应为 15）"
"场景:     " + (Get-ChildItem "$dst\scenes" -Filter *.json).Count + " 个（应 >= 2）"
"env 体积: " + [math]::Round((Get-ChildItem "$dst\env" -Recurse -File | Measure-Object Length -Sum).Sum/1MB,1) + " MB（应约 62.2）"
"numpy:    " + (Test-Path "$dst\env\Lib\site-packages\numpy\__init__.py")
```

### 2.3 生成校验清单（发货前做一次，收货后比对）

```powershell
$dst = 'D:\simkit_delivery'
Get-ChildItem $dst -Recurse -File |
  Get-FileHash -Algorithm SHA256 |
  Select-Object @{n='Path';e={$_.Path.Replace($dst,'')}}, Hash |
  Sort-Object Path |
  Export-Csv "$dst\_SHA256.csv" -NoTypeInformation -Encoding UTF8
(Import-Csv "$dst\_SHA256.csv").Count
```

收货侧比对：

```powershell
$root = 'D:\simkit_delivery'
$bad = @()
Import-Csv "$root\_SHA256.csv" | ForEach-Object {
  $h = (Get-FileHash ($root + $_.Path) -Algorithm SHA256).Hash
  if ($h -ne $_.Hash) { $bad += $_.Path }
}
if ($bad.Count) { "损坏/缺失: "; $bad } else { "全部一致 OK" }
```

## 3. Python 运行时（关键：venv 不能单独拷）

### 3.1 先理解为什么会失败

`env\` 是 `python -m venv` 产物，结构是：

```
env\
├─ pyvenv.cfg                    ← 关键：home 指向"基础解释器"所在的绝对路径
├─ Scripts\python.exe            ← 只是个启动器，不是完整解释器
└─ Lib\site-packages\numpy       ← 真正的依赖在这里
```

`env\Scripts\python.exe` 内部没有 `python313.dll`，也没有标准库（`env\Lib\` 下只有 `site-packages`），
它启动时会去 `pyvenv.cfg` 的 `home` 找基础解释器。

本项目的 `env\pyvenv.cfg` 当前内容（原文）：

```
home = C:\Users\<用户名>\<python 发行版目录>\versions\3.13.12
include-system-site-packages = false
version = 3.13.14
executable = <venv 目录>\.venv\Scripts\python.exe
command = <venv 目录>\.venv\Scripts\python.exe -m venv <项目根>\env
```

也就是说不存在 `C:\Users\<用户名>\...` 的目标机上，直接运行会得到（**实测**）：

```
python.exe : did not find executable at 'C:\NoSuchPython\3.13\python.exe'
退出码 103
```

所以"整体拷目录就能用"的前提是：**目标机上有一份 CPython 3.13 x64，且 `pyvenv.cfg` 指向它。**

### 3.2 方案 A（推荐）：随包带一份便携 CPython，并改 `pyvenv.cfg`

**第 1 步**：把一份 CPython 3.13 x64 的**整个目录**放到 `third_party\python\`。
可以是从任意一台机器复制的便携版目录（含 `python.exe`、`python313.dll`、`Lib\`、`DLLs\`），
体积约 100–150 MB。必须满足：

- 版本是 **3.13.x**（与 `env\Lib\site-packages\numpy` 的 `cp313` ABI 一致）；
- 架构是 **64 位**（`win_amd64`）；
- 目录里 `python.exe` 可用。

**第 2 步**：把 `env\pyvenv.cfg` 指向随包的 CPython。

> 不要"逐行替换"整份文件：原文的 `command` 行含中文路径，用 `-Encoding ascii` 回写会变成
> `???`（无害但脏）。直接重写成最小配置最稳——venv 只认 `home` 和
> `include-system-site-packages` 两个键（已实测）。

```powershell
$root = 'D:\simkit_delivery'
$py   = Join-Path $root 'third_party\python'
$cfg  = Join-Path $root 'env\pyvenv.cfg'

Copy-Item $cfg "$cfg.bak" -Force          # 备份原文件
@(
  "home = $py"
  "include-system-site-packages = false"
) | Set-Content -Path $cfg -Encoding ascii
Get-Content $cfg
```

期望输出：

```
home = D:\simkit_delivery\third_party\python
include-system-site-packages = false
```

原来的 `version` / `executable` / `command` 只是信息性记录，删掉不影响运行。

**第 3 步**：验证（`sys.prefix` 必须是 `env\`，不是 `third_party\python`）：

```powershell
$root = 'D:\simkit_delivery'
& "$root\env\Scripts\python.exe" -c "import sys, numpy; print('python', sys.version.split()[0]); print('prefix', sys.prefix); print('numpy ', numpy.__version__)"
```

期望输出：

```
python 3.13.14
prefix D:\simkit_delivery\env
numpy  2.5.4
```

之后所有命令都用 `& "$root\env\Scripts\python.exe" -m simkit ...` 即可。

### 3.3 方案 B（零改动）：便携 CPython + PYTHONPATH

不动 `pyvenv.cfg`，直接用便携 CPython，把 numpy 目录塞进 `PYTHONPATH`：

```powershell
$root = 'D:\simkit_delivery'
$env:PYTHONPATH = "$root\env\Lib\site-packages"
Set-Location $root
& "$root\third_party\python\python.exe" -m simkit selftest
```

**这一条已实测可行**：用一份便携 CPython 3.13.14 指向 `env\Lib\site-packages`，
`import numpy` 与 `import simkit` 均正常。缺点是每次开新终端都要重设 `PYTHONPATH`。

### 3.4 方案 C：把 numpy 直接塞进便携 CPython

```powershell
$root = 'D:\simkit_delivery'
$sp   = Join-Path $root 'third_party\python\Lib\site-packages'
New-Item -ItemType Directory -Path $sp -Force | Out-Null
Copy-Item "$root\env\Lib\site-packages\numpy*" $sp -Recurse -Force
& "$root\third_party\python\python.exe" -c "import numpy; print(numpy.__version__)"
```

适合"不想要 venv、只想要一个 python 目录"的场景。三条路线任选其一，功能完全等价。

> 若强制要求 `env\Scripts\python.exe` 可用但不想带便携 CPython：也可以在目标机用
> 安装包把 **Python 3.13 x64 装到固定路径**（如 `D:\Python313`），再把 `home` 指向它。
> 需要管理员权限，且要在同一台机器上做一次离线安装。

### 3.5 关于只读介质

从光盘/U盘**直接运行**可能失败或变慢：Windows 上 Python 会在包目录旁写 `__pycache__`
（写失败通常只是警告），但 `out\` 目录必须可写。
**务必先把整个目录复制到本地硬盘再运行**。

## 4. 依赖：只有 numpy，已 vendored

```powershell
$root = 'D:\simkit_delivery'
Get-ChildItem "$root\env\Lib\site-packages" | Select-Object Name
```

```
numpy
numpy-2.5.4.dist-info
numpy.libs
pip
pip-26.1.2.dist-info
```

simkit 的 15 个模块只 `import numpy`（外加标准库 `json/os/math/struct/zlib/argparse/subprocess`），
**没有任何第三方包**。所以：

- 不需要 `pip install`，不需要联网索引；
- 不需要编译器（numpy 已编译好，`numpy.libs` 里是随包的 MKL/OpenBLAS 运行库）；
- 若 numpy 被误删/损坏，用 `_wheels` 离线重装（**不联网**）：

```powershell
$root = 'D:\simkit_delivery'
& "$root\env\Scripts\python.exe" -m pip install --no-index --find-links "$root\_wheels" --force-reinstall numpy
```

> `--no-index` 是关键：它让 pip 完全不访问网络。前提是 `_wheels` 里有
> `numpy-2.5.4-cp313-cp313-win_amd64.whl`（本包已附带，12 MB）。

## 5. Blender（只有可见光传感器需要）

### 5.1 解压

```powershell
$root = 'D:\simkit_delivery'
Expand-Archive -Path "$root\third_party\blender-4.5.1-windows-x64.zip" `
               -DestinationPath "$root\third_party" -Force
Get-ChildItem "$root\third_party" -Recurse -Filter blender.exe | Select-Object FullName
```

解压后应为 `third_party\blender-4.5.1-windows-x64\blender.exe`。

### 5.2 让 simkit 找到它

simkit 的查找顺序（`simkit/optical.py` 的 `find_blender`）：

1. 场景 JSON 的 `optical.blender`
2. 场景 JSON 的 `sensors.optical.blender`
3. 环境变量 `SIMKIT_BLENDER`
4. `<项目根>\third_party\`、`<项目根>\tools\`、`<项目根>\vendor\` 下**名字以 blender 开头**的目录里的
   `blender.exe`（只扫一层，即 `third_party\blender-xxx\blender.exe`）
5. `PATH` 里的 `blender`

最省事：环境变量（**每次开新终端都要设**）：

```powershell
$env:SIMKIT_BLENDER = 'D:\simkit_delivery\third_party\blender-4.5.1-windows-x64\blender.exe'
Test-Path $env:SIMKIT_BLENDER
```

或写进场景 JSON（推荐，一次到位）：

```json
"optical": { "samples": 16, "engine": "CYCLES",
             "blender": "D:\\simkit_delivery\\third_party\\blender-4.5.1-windows-x64\\blender.exe" }
```

> 注意目录名必须**以 blender 开头**、且 `blender.exe` 直接位于该目录内（不要再套一层）。

### 5.3 验证 Blender 本身能离线跑

```powershell
$bl = 'D:\simkit_delivery\third_party\blender-4.5.1-windows-x64\blender.exe'
& $bl -b --factory-startup --version
& $bl -b --factory-startup --python-expr "import numpy; print('blender numpy', numpy.__version__)"
```

第一条打印版本号，第二条确认 Blender 自带 numpy（`render_optical.py` 需要它）。
Blender 便携版**不需要安装、不需要激活、不联网校验**；Windows 首次运行可能弹 SmartScreen
提示，选"仍要运行"即可。

### 5.4 不装 Blender 的影响

只影响可见光。`-s ir,radar`（默认）完全不受影响；一旦请求 `optical`，会立刻报错而不是静默降级：

```
RuntimeError: optical sensor requested but Blender not found (set SIMKIT_BLENDER or optical.blender)
```

## 6. 不需要的东西（明确列出，省得白折腾）

| 项目 | 需要？ | 原因 |
| --- | --- | --- |
| MATLAB / MCR | **否** | 全部算法是 Python+numpy 重写，无 .m/.mat 依赖 |
| 许可证服务器 / 加密狗 | **否** | 无商业组件；Python、numpy、Blender 均为自由许可 |
| 联网激活 / 在线授权 | **否** | 代码无网络调用；Blender 便携版无需激活 |
| GPU / CUDA / 显卡驱动 | **否** | numpy CPU 计算；Blender 后端显式 `cycles.device = "CPU"` |
| Visual C++ 生成工具 / 编译器 | **否** | numpy 是预编译 wheel；便携 CPython 自带 `vcruntime140.dll` |
| conda / Anaconda | **否** | 裸 CPython + 一个 numpy 即可 |
| 管理员权限 | **否** | 便携目录，不写注册表、不装服务、不建计划任务 |
| 显示器 / 交互桌面 | **否** | 纯命令行；Blender 用 `-b` 无头模式 |

## 7. 断网自检（三步，5 分钟内）

**前提**：物理断网（拔网线 / 关无线 / 交换机端口 down），不要只靠"我觉得不需要网"。

### 第 1 步：自检 9 项

```powershell
$root = 'D:\simkit_delivery'
Set-Location $root
& ".\env\Scripts\python.exe" -m simkit selftest
```

通过标准：9 行 `PASS`，末行 `RESULT: ALL PASS`，退出码 0。任何一行 `FAIL` 都不要继续往下走。

### 第 2 步：生成 3 帧演示数据

```powershell
$root = 'D:\simkit_delivery'
Set-Location $root
$sw = [Diagnostics.Stopwatch]::StartNew()
& ".\env\Scripts\python.exe" -m simkit gen -c .\scenes\demo_ir.json -o .\out\offline_check -n 3
$sw.Stop()
"耗时 " + [math]::Round($sw.Elapsed.TotalSeconds,1) + " s（参考基线 2.1-2.3 s）"
```

### 第 3 步：检查文件数与内容

```powershell
$out = 'D:\simkit_delivery\out\offline_check'
$files = Get-ChildItem $out -Recurse -File
"文件总数: " + $files.Count + "（应为 17）"
Get-ChildItem $out -Recurse -File | Group-Object { $_.Directory.Name } | ForEach-Object { "  {0} : {1}" -f $_.Name, $_.Count }
"红外 PNG 尺寸检查:"
.\env\Scripts\python.exe -c "import struct; d=open(r'$out\images\ir\000000.png','rb').read(26); w,h,bd,ct=struct.unpack('>IIBB', d[16:26]); print('  ', w, h, 'bit_depth', bd, 'color_type', ct)"
```

期望：

```
文件总数: 17（应为 17）
  ir : 6              ← 3 张 16bit 红外 + 3 个标注
  ir_preview : 3
  radar : 6           ← 3 张 RD 图 + 3 个标注
红外 PNG 尺寸检查:
   640 512 bit_depth 16 color_type 0
```

### 第 4 步（可选，装了 Blender 才做）：可见光 1 帧

```powershell
$root = 'D:\simkit_delivery'
Set-Location $root
$env:SIMKIT_BLENDER = "$root\third_party\blender-4.5.1-windows-x64\blender.exe"
& ".\env\Scripts\python.exe" -m simkit gen -c .\scenes\demo_optical.json -o .\out\optical_check -n 1 -s optical
Get-ChildItem .\out\optical_check -Recurse -File | Select-Object FullName, Length
```

出现 `images\optical\000000.png`（480×360 RGB，约几十 KB）即通过。若报 Blender 相关错误，
回第 5 节检查路径。

### 一键断言版（可直接贴）

```powershell
$ErrorActionPreference = 'Stop'
$root = 'D:\simkit_delivery'
Set-Location $root

& ".\env\Scripts\python.exe" -m simkit selftest
if ($LASTEXITCODE -ne 0) { throw "selftest 退出码 $LASTEXITCODE" }

& ".\env\Scripts\python.exe" -m simkit gen -c .\scenes\demo_ir.json -o .\out\offline_check -n 3 -q
if ($LASTEXITCODE -ne 0) { throw "gen 退出码 $LASTEXITCODE" }

$n = (Get-ChildItem '.\out\offline_check' -Recurse -File).Count
if ($n -ne 17) { throw "文件数 $n，期望 17" }

if (-not (Test-Path '.\out\offline_check\annotations_ir_coco.json')) { throw "缺少 COCO" }
if (-not (Test-Path '.\out\offline_check\images\radar\000000.png'))  { throw "缺少雷达图" }

Write-Host "断网自检通过：9 项 PASS，17 个文件" -ForegroundColor Green
```

```
   └─ python\                            CPython 3.13 x64（方案 A 必需）
```

### 8.2 打勾清单

| # | 检查项 | 命令/方法 | 通过 |
| --- | --- | --- | --- |
| 1 | 15 个 .py 齐全 | `(Get-ChildItem simkit -Filter *.py).Count` = 15 | ☐ |
| 2 | 三个示例场景齐全 | `Get-ChildItem scenes -Filter *.json` ≥ 2 | ☐ |
| 3 | `env\Lib\site-packages\numpy\__init__.py` 存在 | `Test-Path` | ☐ |
| 4 | `env\pyvenv.cfg` 的 `home` 指向随包 CPython | `Get-Content env\pyvenv.cfg` | ☐ |
| 5 | `env\Scripts\python.exe` 能启动且 `sys.prefix` 指向 `env` | 第 3.2 节第 3 步 | ☐ |
| 6 | `_wheels` 里有 numpy whl（12 MB） | `Get-ChildItem _wheels` | ☐ |
| 7 | （可选）Blender zip 或已解压目录存在 | `Get-ChildItem third_party` | ☐ |
| 8 | `out\` 未被打包进去 | 列目录确认 | ☐ |
| 9 | `_SHA256.csv` 已生成且条数与文件数一致 | 第 2.3 节 | ☐ |
| 10 | 断网自检四步全过 | 第 7 节 | ☐ |

### 8.3 介质与路径注意

- **路径长度**：Windows 默认 260 字符上限。交付根建议就放在 `D:\simkit_delivery`
  这种浅路径，别塞进"新建文件夹(3)\项目\..."深处；`env\Lib\site-packages\numpy\...` 本身已经挺深。
- **中文路径**：本机实测可正常运行（源码与 JSON 均用 UTF-8 打开），但**建议 ASCII**，
  避免压缩/解压工具或第三方脚本按 ANSI 处理导致路径乱码。
- **文件系统**：移动硬盘用 NTFS 或 exFAT 均可；**不要**用会丢文件属性的 FAT32 打包
  `env\`（单文件都没超 4 GB，但权限位/时间戳会丢，不影响运行）。
- **刻盘**：总目录约 330 MB，CD 装不下，用 DVD（4.7 GB）或 U 盘/移动硬盘。
  刻盘前先本地跑一遍第 7 节自检，**刻完再从盘上复制回来跑一遍**。
- **只读介质**：光盘/U盘的只读属性不影响运行，但 `out\` 必须写本地盘——所以
  **先整目录复制到本地硬盘，再从本地盘运行**。
- **杀毒/EDR**：从可移动介质复制出来的 `python.exe`、`blender.exe` 可能被拦截或隔离。
  交付前与目标机管理员确认白名单策略。

## 9. 故障对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `did not find executable at 'C:\Users\...\python.exe'`，退出码 103 | `pyvenv.cfg` 的 `home` 指向目标机不存在的路径 | 第 3.2 节改 `home`/`executable`，或用方案 B |
| `ModuleNotFoundError: No module named 'numpy'` | `PYTHONPATH` 没设 / numpy 被删 | 方案 B 设 `PYTHONPATH`，或 `pip --no-index` 重装 |
| `ModuleNotFoundError: No module named 'simkit'` | 当前目录不是项目根 | `Set-Location $root`，或设 `PYTHONPATH=$root` |
| `RuntimeError: optical sensor requested but Blender not found` | 未解压 / 路径不对 / 目录名不以 blender 开头 | 第 5 节 |
| Blender 报 `ModuleNotFoundError: numpy` | 用了一个裁剪过的 Blender | 换官方便携版（自带 numpy） |
| 生成极慢（>10 s/帧） | 分辨率高 / 波束多 / 机器弱 | 降 `ir_camera.width/height`、降 `n_az·n_el` |
| `PermissionError` 写 `out\` | 从只读介质直接运行 | 复制到本地盘 |
| `KeyError: 'ir_camera'` | 请求了红外但场景里没有 `sensors.ir_camera` | 补相机配置 |
| `KeyError: '<材质名>'` | `mat` 写错 | 用 README 附录 A 的材质名 |
| 中文路径下个别文件乱码 | 工具按 ANSI 处理 | 改用 ASCII 路径 |

## 10. 最短路径速查（老手版）

```powershell
# 1) 拷到本地
robocopy '<项目根>' 'D:\simkit_delivery' /E /XD out __pycache__ /R:1 /W:1

# 2) 放便携 CPython 到 third_party\python，并把 home 指过去
$root='D:\simkit_delivery'; $py="$root\third_party\python"; $cfg="$root\env\pyvenv.cfg"
@("home = $py","include-system-site-packages = false") | Set-Content $cfg -Encoding ascii

# 3) 断网自检 + 生成 3 帧
Set-Location $root
& ".\env\Scripts\python.exe" -m simkit selftest
& ".\env\Scripts\python.exe" -m simkit gen -c .\scenes\demo_ir.json -o .\out\offline_check -n 3
(Get-ChildItem .\out\offline_check -Recurse -File).Count   # 17
```
