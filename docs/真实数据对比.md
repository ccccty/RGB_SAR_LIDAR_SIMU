# 真实飞机数据集与「合成—真实」差距：哪些可量化、哪些可修补

> 调研日期 2026-11-03。范围：可见光 / 红外 / 遥感与 SAR 中的飞机，以及无人机（低小慢）目标。
> 目的：给本仓库的 RGB / IR / RD / LiDAR 生成器定位差距，并把差距落成可执行的验收指标。
> 本文件只写调研结论，不改任何代码。
>
> **可信度标记**：**✔** = 已核对的官方页面或论文原文数值；**○** = 领域内常见引用口径（未逐条回原文核对，量级可信、尾数可能有出入）；**△** = 本文给出的估算或典型量级（附计算依据）。

## 0. 结论先行

1. **公开的真实飞机数据分成三个互不重叠的世界**：地面机位 spotting（FGVC-Aircraft 一类，目标占画面 30%–80%，彩色、百万像素级、但没有距离/姿态元数据）；空中对空或对地小目标（AOT、Anti-UAV 系、Det-Fly、Drone-vs-Bird，目标 5–40 px，多数 640×512 或 1080p，AOT 甚至是 8 bit 灰度）；天基遥感（DOTA / xView / SAR-AIRcraft，俯视、旋转框）。**没有一个**是「机载、远距、RGB+IR+SAR+LiDAR 同目标配准」的数据集。
2. **我们所在工况（20 km、2.2° 视场、640×480、目标约 10–40 px）在公开真实数据里最接近的是 AOT / Anti-UAV，而不是 FGVC-Aircraft**。参照系选错，会把「差距」估错一个数量级：FGVC 的差距是「材质与细节」，AOT 的差距是「退化链与小目标统计」。
3. **真实空对空数据的物理上限很低**：AOT 是 8 bit 灰度、10 Hz、2448×2048；Anti-UAV410 是 640×512 长波红外、25 fps。它们的信息量低于我们的渲染输出。差距不在分辨率，而在**退化链**与**目标在画面中的占比**。
4. **sim2real 落差有硬数字**（同一数据、同一网络）：RarePlanes 上合成单独训练 mAP50 **71.6**，真实单独训练 **94.3**（−22.7 点）；合成预训练 + 10% 真实微调 **91.8**（−2.4 点）。见 §3.1。
5. **落差可分解为四项**：外观统计 Δ_app、分布 Δ_dist、标注 Δ_lab、任务定义 Δ_task。前两项可量化可修补；第三项我们其实**强于**真实数据（有实例图与像素级可见性），只要不丢；第四项要靠数据集契约对齐。
6. **我们的成像链已经具备**：Poisson 散粒、固定 PRNU、读出噪声、12 bit 量化、高斯 PSF、大气斜程、Cycles 运动曝光、IR 的 NETD 与 NUC/AGC、雷达真实 RD 峰值。**缺的是「相机后端」**：Bayer 噪声与去马赛克、JPEG、暗角、色差、畸变、卷帘快门、衍射 MTF、镜头杂光、自动曝光分布、高光肩部。这些全部是 numpy 几十行的事，性价比最高。
7. **按当前参数可以直接算出「太干净」的量级**：3 e⁻ 读出噪声在 30 ke⁻ 满阱、12 bit 下折算到 8 bit 只有 **0.026 DN**，而真实 ISO100 相机暗部 σ ≈ 1.5–3 DN，**暗部噪声低 1–1.5 个数量级**；σ = 0.6 px 高斯 PSF 的 MTF50 ≈ **0.34 cyc/px**，真实 f/8 衍射 + 像元积分约 **0.20–0.30**，且真实 MTF 有旁瓣，高斯没有。
8. **最该补的不是「更好看的图」，而是「可测量的退化统计」**。验收只用 6 个数字就够起步：功率谱斜率 α、MTF50、暗部噪声 σ、8×8 块效应比、饱和像素比、目标像素高度分布。

- **军用机型识别**的公开图像数据极少：FGVC-Aircraft 以民航为主，军用机多靠航展 spotter 照片零散分布，没有成规模的公开基准。这一块只能靠三维模型渲染补，也正是合成数据的合理用武之地——但也就失去了真实测试集，只能做「留出机型」的泛化实验。

### 1.5 读表得到的六个结构性结论

1. **规模断层**：可见光地面 10⁴ 图；空对空 10⁶ 帧但目标 5–40 px；遥感 10³–10⁴ 图但单图 4000²；SAR 10³ 切片。我们的生成器目前是「几十到几百帧 × 640×480」，与任何一类都差 2–4 个数量级——**但对小目标检测，帧数比分辨率更值钱**。
2. **位深与压缩**：AOT 是 8 bit 灰度 PNG（无损），DOTA 是 PNG，FGVC 是 JPEG。真实数据的「压缩史」是不统一的，我们的输出目前是「12 bit 计数 → 8 bit sRGB PNG」，等价于「无损、无压缩、无相机后端」。
3. **标注形态**：框占绝对主导；DOTA 用 8 自由度四边形；只有 SIRST 系列用像素掩膜；只有 Anti-UAV / RGBT-Tiny 带属性（遮挡、出画、热交叉）。**属性标注是稀缺品**，而我们天生就有（实例图 + 深度 + 可见性），这是可以反向输出的优势。
4. **公开性分层**：AOT 是 CDLA-Permissive（最宽松），DOTA 限学术，FGVC 限非商用，Anti-UAV 要申请，SenSiAC 受限。做对比实验时只能用前三类。
5. **三个真空区**：① 机载、>5 km 的真实飞机图像（AOT 的 encounter 上限是 700 m 量级）；② 同一目标的 RGB/IR/SAR/LiDAR 配准数据（完全没有）；③ 大规模真实 SAR 飞机切片（约 4k）。**我们的差异化价值就在②，而①决定了我们没有可直接对标的真实测试集**。
6. **参照系必须分域**：材质/纹理要对标 FGVC；退化链要对标 AOT 与 Anti-UAV；几何/旋转框要对标 DOTA；SAR 散射要对标 SAR-AIRcraft。用一个参照系统管全部，必然得出错误结论。

## 2. 真实数据到底难在哪（按成因分类，尽量给数）

### 2.1 光照与曝光

- **逆光/剪影**：太阳在目标后方时，机身处于阴影，目标只剩轮廓与边缘。FGVC-Aircraft 里这类样本占比不低（spotter 常在跑道端逆光拍）。此时**颜色信息几乎为零**，判别只能靠形状与发动机/尾翼布局。
- **太阳闪烁（glint）**：金属蒙皮与座舱盖的镜面反射会在局部产生远高于漫反射的辐亮度，真实照片里表现为 1–50 px 的饱和斑，并且带 bloom。AOT 的灰度相机在迎头姿态下整机可能饱和成一块白斑。
- **夜景/低照**：RGB 通道噪声主导，色彩失真严重；红外则出现「热交叉」（目标与背景同温），Anti-UAV 系列专门把这个列为属性。
- **云影与地面反照率变化**：DOTA 场景里阴影长度与方向随太阳高度角变化，同一机场不同时次的图像统计差异极大。
- **量化表现（△ 典型量级）**：日照场景饱和像素占 0.1%–3%；逆光目标与天空的对比度可低到 < 5 DN；夜景 8 bit 图像暗部 σ 可达 5–15 DN。

### 2.2 大气与传输

- **对比度随距离指数衰减**：t = exp(−βR)。取能见度 20 km 的霾（β ≈ 0.2 km⁻¹），**20 km 处 t ≈ 0.018**——目标辐射几乎全部被路径辐射淹没。这从物理上解释了真空区①：真实机载远距图像本来就极难获得，公开数据自然没有。
- **前向散射与太阳眩光**：太阳接近视轴时，气溶胶前向散射会在目标附近叠加一个缓变亮场，等效降低局部对比度并抬高黑电平。
- **湍流**：长焦、低空、跨温差层时，MTF 会明显下降且随时间抖动。我们的 PSF 是固定高斯，无法表达「同一场景不同帧清晰度不同」。
- **量化表现（△）**：霾天 5–10 km 图像的整体对比度（RMS contrast）可比晴天低 40%–60%；暗通道先验估计的透射率 t 在 0.3–0.7 之间且空间方差不小。

### 2.3 传感器与光学链（差距最集中的地方）

| 效应 | 真实典型量 | 后果 | 我们当前 |
|---|---|---|---|
| 运动模糊 | 1/1000 s 曝光 × 200 m/s 相对速度 = 0.2 m；20 km 处角速度对应数像素 | 边缘方向性拖尾，频域出现零点 | 有（Cycles 运动曝光），但**曝光时间/角速度分布未与真实对齐** |
| 卷帘快门 | 行读出 10–30 µs/行，1080p 全帧 10–30 ms | 横滚时垂直线倾斜 1°–3°，螺旋桨变形 | 无 |
| 镜头畸变 | 广角桶形 −2%…−8% | 边缘直线弯曲，框不再轴对齐 | 无（观测里显式写 `distortion_model="none"`） |
| 暗角 | cos⁴ 照度律，角落 −0.3…−1.5 EV | 图像边缘变暗，与大气衰减混淆 | 无 |
| 色差 | 角落 R/B 通道错位 0.5–2 px | 高对比边缘出现紫/绿边 | 无 |
| 衍射 | f/8、5 µm 像元 → Airy 斑直径约 2 px，MTF50 ≈ 0.2–0.3 cyc/px | 高频截止，无「完美锐利」 | 高斯 σ=0.6 px → MTF50 ≈ 0.34，**偏锐且形状不对** |
| 散粒/读出噪声 | ISO100 暗部 σ ≈ 1.5–3 DN，亮部 1–2 DN | 噪声随信号变化 | 有，但**按 8 bit 折算暗部仅 0.03–0.15 DN**（见 §4.5） |
| 固定模式噪声 | PRNU 0.1%–1%，另有行/列固定模式 | 平场不均匀 | 有（0.1%），无行/列模式 |
| 去马赛克 | CFA 插值产生拉链纹、彩色摩尔纹 | 细网格（蒙皮接缝、跑道灯）出现伪彩 | 无（直接在 RGB 域加噪声，物理上错位） |
| JPEG | q 75–95、4:2:0 色度抽样、8×8 块 | 高频被压，色边被抹 | 无（PNG） |
| 镜头杂光/鬼影 | 强光源在视场内产生低对比光斑 | 黑电平抬升、局部对比度下降 | 无（`glare` 只是干扰类别，非光学杂光） |
| 坏点/热像素 | 0.01%–0.1% | 稀疏亮点，干扰小目标检测 | 无 |
| 自动曝光 | 会因天空占比剧烈变化，帧间跳动 | 同一序列亮度不连续 | 有，但**分块不保证同参考**（文档已声明） |

### 2.4 目标状态与几何

- **极小目标**：AOT 平均每帧 1.3 个目标，大量目标在 10–20 px；Anti-UAV410 常见 < 20 px；RGBT-Tiny 直接把「tiny」写进名字。此时**检测器实际依赖的是「一小团亮度的时空一致性」，而不是形状**。
- **遮挡与出画**：Anti-UAV 系有 occlusion / out-of-view 属性；AOT 的 encounter 定义要求目标连续可见 ≥ 30 帧。真实数据里「部分出画」的框常常被裁到图像边界，标注习惯是**框贴边**，不是完整目标框。
- **姿态分布**：真实空对空以迎头/尾追小角度为主（|方位角| < 30° 占多数），侧向大姿态样本稀少；卫星俯视是顶视，地面 spotting 是仰视。**没有任何单一真实数据集覆盖全姿态球**——这既是合成的优势，也是合成最容易「均匀分布」而脱离真实先验的地方。
- **螺旋桨**：真实照片里是半透明圆盘 + 桨叶残影；渲染要么静止要么全糊。
- **尾迹**：远距目标常常先看到凝结尾迹再看到飞机，这是真实数据里的强先验，合成里几乎没有。

### 2.5 背景杂波与混淆物

- **云**：边缘高频、亮度接近目标、形状随机。云边缘是空对空检测最主要的虚警来源之一。
- **飞鸟**：Drone-vs-Bird 挑战的核心结论是——**单帧形状不足以区分鸟与无人机，必须用时序运动学**。
- **风筝/气球/滑翔伞**：低小慢场景的常见混淆物。
- **建筑物/塔吊/跑道灯**：地面仰拍时大量竖直线与点光源。
- **其他飞机**：编队、起降排队、停机坪密集排列（DOTA 里停机坪常出现 20+ 架密集目标，框互相重叠）。
- **量化表现（△）**：真实小目标数据集的「负样本/无目标帧」比例很高（AOT 有 3.31M 帧无目标，占 56%），而合成数据集通常每帧都有目标——这直接改变检测器的先验与误报率。

### 2.6 标注与任务定义

- **标注噪声**：真实框有 1–3 px 抖动，小目标漏标普遍（AOT 声称全标，是少数例外）。
- **可见性缺失**：大多数数据集没有 truncation / occlusion 标志，训练时把「贴边半架飞机」当作完整目标。
- **类别长尾**：RarePlanes 合成数据里有 122 种机型，只有 44 种与真实重叠、35 种出现在真实测试集——**分类头的一半在真实域里没有对应样本**。
- **属性稀缺**：只有 Anti-UAV / RGBT-Tiny 一类给了属性标签；这反过来说明，如果我们输出「可见比例、遮挡等级、出画标志、像素级可见性」，是超出公开数据平均水平的。

## 3. 已发表的 sim2real 落差（有数字的部分）

### 3.1 RarePlanes：唯一「真实+合成同源」的飞机数据集

数据集本身（✔）：真实部分 253 景 WorldView-3、112 个地点、22 国、2,142 km²、14,700 架人工标注；合成部分 50,000 图、9,331 km²、约 630,000 个标注；两者共享 10 个细粒度属性（长度、翼展、翼形、翼位、翼展等级、推进方式、发动机数、垂尾数、有无鸭翼、用途），可组合出 1–110 个类别。

同一数据、同一网络（DetectNet_v2/ResNet18，NVIDIA TAO 官方复现，2021）的实测数字（✔）：

| 训练数据 | 真实测试集 mAP50 | 相对真实单独训练 |
|---|---|---|
| 100% 真实 | **94.3**（best epoch 94.23，eval 94.26） | — |
| 100% 合成 | **71.6**（日志中各 epoch 58.1 / 65.1 / 64.3 / 68.2 / **71.6** / 68.6） | **−22.7 点** |
| 合成预训练 + 10% 真实微调 | **91.8** | −2.4 点 |

三个可直接引用的结论：
1. **纯合成的外观落差约 20 点量级**（在这个任务上），不是几个点。
2. **少量真实数据（10%）就能收回绝大部分落差**（−22.7 → −2.4），说明落差的主要成分是「域偏移」而非「信息缺失」。
3. 但这个 10% 的真实数据是**同分布、同传感器、同机场类型**的；跨传感器/跨距离时不能照搬这个结论。

另一条同样重要、但常被忽略的数字（✔，CosmiQ/DownlinQ 复现记录）：最初合成集约 32,000 图 / 225,000 架 / **122 种机型**，其中只有 **44 种**与真实数据重叠、**35 种**出现在真实测试集。也就是说，**合成数据的类别空间有一大半在真实域里无法评估**——这是「分布落差」里最容易被低估的一项。

### 3.2 后续跟进：合成数据不是万能

- **IQT《Synthesizing Robustness》(2021, Van Etten)**：在 RarePlanes 上做稀有类别（14 类 + Other，部分类只有 6 个真实样本）的 mF1 实验，结论是「**策略性地增强真实数据，效果几乎等同于加入合成数据**」，且合成数据的收益高度依赖预训练+微调流程与类别覆盖（✔ 结论，具体 mF1 数值未逐条核对，标 ○）。
- **RarePlanes Soar Higher (WACV 2023 Workshop)**：用自监督预训练替代「合成预训练」，在资源受限与合成数据场景下缩小差距——说明「合成数据的作用有一部分其实是预训练的作用」（○）。
- **AeroGen (2024)**：扩散模型生成遥感图像用于检测，在 DIOR / DIOR-R / HRSC 上 mAP 分别 +3.7 / +4.3 / +2.43（✔ 摘要数字）。这代表「生成式合成」的上限量级：**个位数 mAP**，且是在真实数据已经参与训练的前提下。
- **DiffDet4SAR (2024)**：SAR-AIRcraft-1.0 上 mAP75 = 68.2%（✔），说明真实 SAR 飞机检测本身还有很大空间；合成 SAR 若只在「理想散射中心」上训练，会系统性高估。

### 3.3 落差分解（本文的归纳，△）

把观测到的 mAP 落差写成四项之和：

    Δ_total ≈ Δ_app（外观/退化） + Δ_dist（尺度/姿态/背景/类别分布） + Δ_lab（标注） + Δ_task（任务与评价定义）

经验量级（△，来自上述实验与常见检测文献的归纳，**不是单个论文的数字**）：
- 仅传感器退化不同（同分布、同场景、只换噪声/MTF/压缩）：**3–10 点**。
- 加上尺度/背景/类别分布不同：**10–25 点**（RarePlanes 的 −22.7 落在这里）。
- 标注口径不同（贴边框 vs 完整框、漏标小目标）：可再造成 **2–8 点**的「假落差」——这部分不是模型差，是评价口径差。

这个分解的实用价值：**先测 Δ_app，再测 Δ_dist，不要一上来就做风格迁移**。因为风格迁移只能动 Δ_app，而动不了 Δ_dist（反而常常破坏小目标的几何）。

### 3.4 域适应手段与已知效果

| 手段 | 代表工作 | 效果量级 | 适用/风险 |
|---|---|---|---|
| 少量真实微调 | RarePlanes/TAO (2021) | −22.7 → −2.4（10% 真实）✔ | 最有效，但需要真实数据 |
| 自监督预训练 | RarePlanes Soar Higher (2023) | 缩小差距，接近合成预训练收益 ○ | 无需标签，成本中 |
| 传感器退化增广（噪声/模糊/JPEG） | 通用做法 | 通常 2–6 点 △ | 便宜、无幻觉，**首选** |
| 风格迁移 / CycleGAN 类 | 多篇遥感 DA | 改善外观，常见 3–8 点 △ | 可能引入伪影、破坏小目标与几何一致性 |
| 课程式混合采样（synth:real 比例） | RarePlanes 系 | 与混合比例强相关 △ | 需要调参，易过拟合测试集 |
| 测试时自适应 | 通用 | 1–4 点 △ | 部署侧，离线数据集不适用 |

**注意**：这些数字不能横向相加，基线、测试集、评价口径都不同。能横向比较的只有同一实验内的差值（如 §3.1 那三行）。

## 4. 可量化的图像统计量

### 4.0 度量框架与三条纪律

三层：
- **L1 像素统计**：功率谱、噪声、MTF、压缩痕迹、色彩、动态范围。便宜、可解释、直接对应「相机后端缺什么」。
- **L2 感知/分布**：FID/KID、BRISQUE/NIQE。贵、需要足够样本、对内容敏感。
- **L3 任务级**：把合成数据训练、真实数据测试的 mAP 落差按 §3.3 分解。最贵，但唯一能证明「补得对」。

三条纪律：
1. **同内容比较**：功率谱、MTF、噪声都必须比较「同类内容」（天空块、机身块、草地块），否则测的是场景而不是成像。
2. **分区域统计**：整幅图的统计量会被天空/地面占比支配。至少分「天空、地面、目标裁剪块」三类。
3. **报告分布而非单值**：所有指标给中位数 + IQR，不要给一个均值就下结论。

### 4.1 径向平均功率谱斜率 α（首选指标）

**定义**：自然图像的功率谱近似 P(f) ∝ f^(−α)，幅度谱 ∝ f^(−α/2)。自然照片 α ≈ 2（幅度 1/f，Field 1987；Torralba & Oliva 2003 给出同类结论）。

**算法**（numpy，约 10 行）：
1. 转灰度（或只用 G 通道），减均值，乘 Hann 窗抑制泄漏；
2. `F = np.fft.fftshift(np.fft.fft2(x))`，`P = np.abs(F)**2`；
3. 以图像中心为原点算半径 r，按对数分箱（如 64 箱，f ∈ [1/64, 0.45] cyc/px）求平均；
4. 对 `log10(P)` ~ `log10(f)` 做最小二乘，斜率取负得 α。

**真实典型值（△）**：α = 1.8–2.2（自然照片，512² 裁剪，8 bit sRGB）。
**合成偏离方向（△）**：
- 纹理不足 + 无噪声 → 高频能量掉得快，**α 升到 2.5–3.5**；
- 噪声/锐化过强 → 高频被抬平，**α 降到 1.5–1.8**；
- 更可靠的判据不是单一 α，而是**双斜率**：低频段 α₁、高频段 α₂ 与拐点 f_k。真实照片在 f ≈ 0.3–0.4 cyc/px 附近因 MTF 与压缩出现「二次下折」；渲染图如果没有 MTF 与压缩，这个下折不出现。

**补法**：先补 MTF（衍射 + 像元积分 + 轻微离焦），再补噪声底，最后补 JPEG。顺序错了会互相掩盖。

### 4.2 高频缺口 / 噪声底（PSD 平坦度）

**定义**：把 PSD 的高频段（0.35–0.5 cyc/px）与中频段（0.1–0.2）比值化，得到「高频相对能量」H。真实照片 H 受 MTF 与压缩双重压制；纯渲染 H 偏高（完美边缘）或偏低（过平滑）。
**真实典型值（△）**：H ≈ 0.02–0.15，依内容与压缩而定。
**偏离方向**：无 AA、无 MTF 的渲染 H 可达 0.3–0.6，并在 Nyquist 附近出现**混叠尖峰**（周期性条纹图案会出现离散亮点）。
**补法**：像元积分（box filter）+ 衍射 MTF + 适度降采样；不要在渲染后做锐化。

### 4.3 拉普拉斯方差（清晰度/离焦）

**定义**：`Var(Laplacian(I))`，3×3 核 `[[0,1,0],[1,-4,1],[0,1,0]]`。经典自动对焦指标（Pech-Pacheco 等 2000）。
**真实典型值（△）**：512² 裁剪、手持长焦、合焦：100–1000；明显离焦 < 50；手机近摄可到 2000+。
**偏离方向**：渲染图在无 AA、无噪声时常常 **> 1000–3000**（边缘过陡）；加了噪声又会虚高（Laplacian 放大噪声）。
**注意**：这个指标对噪声极敏感，**必须先去噪或在 σ=1 高斯平滑后测**，否则它会同时惩罚「太锐」和「太噪」。
**补法**：与 MTF 一起看，不要单独用。

### 4.4 MTF50 / 斜边法

**定义**：对一条斜边（knife edge）求边缘扩散函数 ESF，微分得 LSF，FFT 取模归一化得 MTF，MTF=0.5 处的空间频率即 MTF50（cyc/px）。
**真实典型值（△）**：f/8、5 µm 像元、含衍射与像元积分：**0.20–0.30 cyc/px**；大光圈好镜头可到 0.35。
**我们当前（计算值）**：σ = 0.6 px 高斯 → `MTF(f)=exp(-2*pi^2*sigma^2*f^2)`，MTF50 ≈ **0.34 cyc/px**，且**形状是单调高斯，没有衍射旁瓣**。
**补法**：把 PSF 换成「衍射 Airy ⊗ 像元积分 ⊗ 轻微离焦 ⊗ 运动模糊」的级联，σ 作为可调参数；顺带获得正确的旁瓣与振铃。

### 4.5 噪声：σ(I) 曲线、通道相关性、噪声 PSD

**算法**：
- 平坦块估计：Immerkær (1996) 掩膜 `[[1,-2,1],[-2,4,-2],[1,-2,1]]`，σ = sqrt(π/2)/(6(W−2)(H−2)) · Σ|conv|；或小波 MAD：σ = median(|HH₁|)/0.6745。
- 信号相关性：把图像按亮度分 10 档，每档取平坦块，画 σ vs I，拟合 `sigma^2 = a*I + b`（a 为散粒项，b 为读出项）。
- 通道相关性：平坦块上算 corr(R−G, G−B)。
- 噪声 PSD：平坦块去均值后 FFT，看是否白（真实噪声有色，且 JPEG 后高频被压）。

**真实典型值（△）**：ISO100：暗部 σ 1.5–3 DN，亮部 1–2 DN；ISO800：暗部 5–12 DN。通道相关 0.3–0.7（去马赛克后亮度噪声在通道间相关）。
**我们当前（按代码参数计算，✔ 可复核）**：
- 读出噪声 3 e⁻ / 满阱 30,000 e⁻ × 4095 counts → **0.41 count（12 bit）≈ 0.026 DN（8 bit）**；
- 暗部（线性 0.01，300 e⁻）散粒 σ = 17 e⁻ → 0.12 DN；**8 bit 量化噪声本身就有 0.29 DN**，所以暗部总 σ ≈ 0.3 DN；
- 亮部（线性 0.8，24,000 e⁻）散粒 σ = 155 e⁻ → 约 0.6 DN。
→ **暗部噪声比真实低约 5–10 倍，亮部低 2–3 倍，σ(I) 曲线的斜率也不对**（真实相机的读出+暗电流项在暗部占主导）。
**补法**：在 CFA（Bayer）域加噪声（散粒 + 读出 + 暗电流 + 行/列固定模式），再做去马赛克；不要在三通道 RGB 上独立加噪——那会产生真实相机里不存在的「彩色噪点」。

### 4.6 JPEG / 压缩痕迹

**算法**：块效应比 B = 8 像素网格线上的平均梯度 / 非网格线上的平均梯度；再检测色度抽样（Cb/Cr 是否在 2×2 块内恒定）。
**真实典型值（△）**：JPEG q≈85：B ≈ 1.05–1.2；q≈70：B ≈ 1.15–1.3；PNG/无损：B ≈ 1.0。
**偏离方向**：我们输出 PNG，B = 1.0，且没有 4:2:0 色度模糊 → 彩色边缘过于锐利，高频 PSD 偏高。
**补法**：训练/评估两条流：一条保留无损（做指标基准），一条做随机 JPEG（q ∈ [70,95]，4:2:0），后者才是「像真实照片」的那条。

### 4.7 色彩：colorfulness、Lab 分布、白平衡偏差、CCM

- **colorfulness**（Hasler & Süsstrunk 2003）：`M = sqrt(sigma_rg^2 + sigma_yb^2) + 0.3*sqrt(mu_rg^2 + mu_yb^2)`，rg = R−G，yb = 0.5(R+G)−B。真实户外照片 M ≈ 20–40（△）；渲染图常因「物理正确的线性→sRGB」而偏灰（M 偏低）或饱和过高。
- **Lab a\*b\* 分布**：对天空、草地、机身漆面分别统计，比较均值与协方差（可用 EMD / KL）。
- **白平衡偏差**：真实相机 AWB 有 200–800 K 的偏差且与场景相关；我们的输出是「理想白点」，天空色温过于标准。
- **相机色彩矩阵（CCM）缺失**：真实相机在 sRGB 输出前会做 3×3 CCM，改变色相与饱和度；直接从场景线性 RGB 做 sRGB OETF，会导致「同一材质在渲染图与照片里色相不同」。

**补法**：加一个随机的 CCM + AWB 增益 + 轻微饱和度曲线；这是最便宜的「色彩域随机化」。

### 4.8 动态范围与截断

**算法**：统计 0 与 255 的像素比例、直方图两端肩部形状、以及「高光滚降」的斜率（对 250–255 区间做线性拟合）。
**真实典型值（△）**：日照场景 255 占比 0.1%–3%，0 占比 < 0.5%（有黑电平抬升，真正的 0 很少）；高光肩部是平滑滚降，不是硬切。
**偏离方向**：渲染图要么 0% 截断（完全无高光），要么硬切（大量 255 且无过渡）。
**补法**：曝光扫描 + 高光肩部（filmic/ACES 类 tonemap 的非线性段）+ 太阳闪烁的镜面 BRDF；同时加 1–3 DN 的黑电平偏置。

### 4.9 暗角（vignetting）

**算法**：对平坦区域（晴空、均匀草地）拟合径向亮度 `L(r)/L(0) ≈ cos^4(theta)`，报告角落 EV 落差。
**真实典型值（△）**：广角 −0.5…−1.5 EV；长焦 −0.1…−0.4 EV。
**偏离方向**：渲染 0 EV，且与大气衰减叠加后更难分辨。
**补法**：乘 cos⁴ 因子 + 轻微机械渐晕；注意与大气项分开记录，否则无法归因。

### 4.10 色差（lateral CA）

**算法**：取角区高对比边缘，分别对 R/B 通道做亚像素互相关，报告位移（px）。
**真实典型值（△）**：角落 0.5–2 px，中心 < 0.3 px。
**偏离方向**：渲染 0。
**补法**：R/B 通道绕光心做 1±k 的缩放重采样（k ~ 1e-4…1e-3），配合畸变一起做。

### 4.11 大气透射（暗通道先验）

**算法**：He 等 (2009) 暗通道：`J_dark(x) = min_{y in Omega(x)} min_c J_c(y)`，Ω 取 15×15；A 取暗通道最亮 0.1% 像素的均值；`t = 1 - omega*min(J_dark)/A`，ω ≈ 0.95。统计 t 的中位数、空间方差、以及与距离的相关性。
**真实典型值（△）**：晴空远景 t 0.7–0.9；霾 0.3–0.6；云底/逆光 0.2–0.5。
**偏离方向**：解析大气模型给出的 t 在整幅图上过于平滑、与距离的相关性过强（真实有云影、局地霾、前向散射的二维结构）。
**补法**：加二维气溶胶/云阴影场 + 前向散射项；并允许 t 与距离的相关性偏离纯指数。

### 4.12 目标级分布（数据集层面，最容易被忽略）

| 量 | 怎么算 | 真实参考 | 我们该怎么用 |
|---|---|---|---|
| 目标像素高度 | 从标注取 bbox 高，报 p5/p50/p95 | AOT 中位约 10–20 px；Anti-UAV 常见 < 20 px（△）；FGVC 中位 > 200 px | 我们的 20 km 场景约 10–40 px，**对标 AOT/Anti-UAV 而非 FGVC** |
| 长宽比与朝向 | bbox w/h、旋转角 | 俯视遥感接近翼展/机长比；空对空随姿态变化大 | 检查是否「均匀分布」——真实是**迎头/尾追为主** |
| 可见比例 | 目标可见像素 / 完整投影面积 | 真实数据无此标注（我们要自己造） | 我们天生有实例图，应输出并统计 |
| 出画率 | 框贴边比例 | 真实小目标数据集里不低 | 采样时显式模拟，别只生成「完整居中」目标 |
| 无目标帧比例 | 空帧占比 | AOT 56%（✔ 3.31M/5.9M） | 我们的数据集应保留相当比例空帧/纯背景帧 |
| 姿态角分布 | 由 GT 位姿统计 | 真实空对空集中在小离轴角 | 用于构造「真实先验采样」，而不是均匀采样 |

### 4.13 感知指标（谨慎使用）

- **FID / KID**：在 Inception-v3 特征上算真实 vs 合成的分布距离。必须**分域**算（天空块、机身裁剪、机场地面），整图 FID 会被场景构成支配。样本量至少各 2,000 张，否则 KID 方差很大。
- **BRISQUE / NIQE**：无参考质量分。真实照片 BRISQUE 约 20–40（越低越好）、NIQE 约 3–5.5（△）；渲染图常常 NIQE < 3（「太干净」）或加入噪声后跳到 5–7（「太脏」）。
- **纪律**：这两个指标只能用于**同内容对比**（同一场景、同一视角、只换成像链），不能用于「我们的数据集 vs 网上随便一批照片」。

## 5. 我们优先该补什么（按性价比排序）

排序依据：**影响指标数 × 实现成本⁻¹ × 是否可验收**。「代价」按本仓库现状估（numpy + Blender CPU，无新依赖）。

| # | 补什么 | 为什么（对应差距） | 代价 | 验收指标 | 备注 |
|---|---|---|---|---|---|
| 1 | **相机后端退化链**：Bayer 域噪声（散粒+读出+暗电流+行列 FPN）→ 去马赛克 → 暗角 → 色差 → 畸变 → 随机 JPEG(q 70–95, 4:2:0) | 一次对齐 6 个指标（α、H、MTF50、暗部 σ、通道相关、块效应比）；是「像不像照片」的主因；真实数据无一例外都经过这条链 | 低（1–2 天，纯 numpy） | §4.14 前 6 行全部落区间 | 现有 `optical_sensor.py` 直接在 RGB 域加噪，需要改成 CFA 域；这是**最高优先级** |
| 2 | **曝光与高光**：自动曝光分布（按天空占比跳变）、高光肩部、太阳闪烁（GGX 镜面 + bloom） | 决定饱和像素比与动态范围；逆光是真实数据最普遍的难点；glint 是红外/可见光都有的强特征 | 中（需要材质高光与 tonemap 改造） | 饱和像素比、直方图肩部形状、目标局部对比度 | 与 #1 的 JPEG/量化有耦合，先做 #1 再做这个 |
| 3 | **目标采样分布**：按真实先验采距离/姿态/出画/空帧比例（迎头尾追为主、log-uniform 距离、10%–50% 空帧、显式贴边裁切） | 分布落差是最大的一项（RarePlanes −22.7 点里的大头）；而且**零渲染成本**，只改采样器 | 极低（半天） | 目标高度 p5/p50/p95、姿态角直方图与真实 KL、空帧比 | 我们现在的场景是「设计好的交战几何」，天然偏离真实分布 |
| 4 | **运动模糊与快门契约**：曝光时间/角速度与真实相机对齐，螺旋桨单独建模（盘状模糊 + 桨叶残影） | 运动曝光已实现，但参数分布未对齐；螺旋桨是航空图像独有的高频特征 | 低（参数 + 一个贴片/着色） | 边缘 PSF 长度/方向的分布；桨盘区域的高频能量 | 与 #1 的 MTF 叠加时注意顺序（先运动后光学） |
| 5 | **大气非均匀**：二维气溶胶/云阴影场、前向散射、湍流导致的帧间 MTF 抖动 | 真实远距图像的对比度结构是二维的；解析模型过于平滑，暗通道 t 的方差偏小 | 中（需要噪声场 + 每帧 MTF） | 暗通道 t 的中位数/方差、与距离的相关性 | 20 km 场景 t ≈ 0.02，本来就看不清——这本身要如实呈现，而不是「调亮」 |
| 6 | **Hard negatives**：鸟、云、风筝、建筑、其他飞机、跑道灯；从公开真实数据挖补丁做背景板 | 真实数据的负样本比例高（AOT 56% 空帧）；虚警率是部署指标；合成数据集普遍缺 | 低–中（数据整理 + 贴片合成） | 每千帧虚警数、FP 来源分类 | 可先用 Drone-vs-Bird 的鸟片段做贴片 |
| 7 | **材质与纹理**：蒙皮接缝、铆钉、脏污、编号、漆面老化、发动机热部件 | 影响 PSD 中频段与 FID；FGVC 类数据的核心差距；也是「一眼假」的主要来源 | 高（美术资产 + UV） | 目标裁剪块的 α、中频能量、FID | 优先级低于 1–4，因为它只影响近距/大目标 |
| 8 | **标注契约**：输出可见比例、遮挡等级、出画标志、像素级可见性、空帧标志 | 真实数据缺这些；我们有实例图，几乎零成本；能直接提升训练价值与可信度 | 极低（已有实例图与深度） | 标注字段完整率、与真实标注习惯的一致性抽查 | 这是**唯一我们比真实数据强**的地方，别浪费 |
| 9 | **规模**：序列级 10 Hz、10⁴–10⁵ 帧、多场景/多机型/多天气 | 帧数比分辨率更值钱（AOT 5.9M 帧 vs 我们几十帧）；检测器需要序列统计 | 高（算力） | 有效帧数、场景/机型覆盖度 | 用参数化场景库 + 低分辨率快渲，再对少量样本高分辨率精渲 |
| 10 | **跨模态一致性**：同一目标的 RGB/IR/SAR/LiDAR 配准与物理一致性 | 公开数据完全没有（真空区②）；这是本项目的差异化 | 中（已有配准框架） | 质心/IoU/深度一致性（已有指标）+ 跨模态强度相关性 | 不要为了「看起来一致」而牺牲各模态独立的物理正确性 |

**一条经验法则**：1–4 项做完，§4.14 的 12 个指标里能对上 10 个；5–6 项决定「检测器在真实数据上会不会崩」；7 项以后是「锦上添花」，但对**近距大目标**（FGVC 类）不可省。

## 6. 不该做 / 补不了的

1. **不要追最低 FID**。FID 会被某个真实子集的场景构成支配，追它等于把生成器过拟合到那批照片；分域 FID + 任务指标才有意义。
2. **不要声称绝对辐射标定**。没有实测传感器与大气数据，任何「绝对辐亮度正确」的说法都不可验证；现有文档已经这样声明，应保持。
3. **不要模仿真实标注噪声**。真实框有 1–3 px 抖动、小目标漏标；我们应该保留干净 GT，另存一份「模拟标注噪声」的变体用于鲁棒性实验，而不是把噪声写进主集。
4. **不要用风格迁移替代物理退化**。GAN 风格迁移能改外观统计，但会破坏小目标的几何与跨模态一致性；在我们这种「目标只有几十像素」的场景里风险大于收益。
5. **补不了的**：真实大气湍流的瞬时实现、真实传感器故障模式（镜头污渍、坏点图样）、真实飞行员的姿态决策分布。这些只能用随机化近似，不能声称还原。

### 7.2 本仓库成像链的现状（读代码所得，供对齐）

- 航空场景：640×480、FOV 2.2°、X 波段 2.5 MHz、波束 2°×6°；20 km 级距离下目标约 10–40 px。
- RGB：`optical_sensor.py` —— 场景线性 RGB → 大气斜程透射 + 空气光 → 高斯 PSF（σ=0.6 px）→ 满阱 30,000 e⁻、读出 3 e⁻、PRNU 0.1%、12 bit → sRGB OETF → uint16 counts + uint8 图。
- **缺**：Bayer/去马赛克、暗角、色差、畸变（观测里 `distortion_model="none"`）、卷帘、衍射 MTF、镜头杂光、JPEG、黑电平、行/列固定模式。
- IR：NETD 30 mK、PSF 1.2 px、NUC、AGC、检测器计数域量化 —— 相对完整，但同样缺镜头后端与 AGC 的真实抖动。
- 标注：有实例图、深度、可见性统计 —— **这是超出公开数据平均水平的部分**，应继续强化（可见比例、出画、遮挡等级）。

### 7.3 一句话给决策者

真实数据里没有我们的工况（机载、20 km、多模态配准），所以「差距」不能靠找一个真实数据集对齐来解决；能做的、也是收益最高的，是**把相机后端与目标分布这两件事补到可测量**，然后用 §4.14 的 12 个数字作为验收门槛，用 §3.1 的实验范式（同网络、同测试集、只换训练数据）来证明补齐之后任务指标确实上升。
