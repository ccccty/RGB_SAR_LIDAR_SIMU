# 2026-11-01 雷达 RD 成像与检测真实性改进

## 范围与兼容性

保留上一轮的弱回波保留、平台相对速度、补采样返回不继承地面功率等修复。
新增 `sensors.radar.detector: "rd_threshold"`，在**实际合成的 RD 功率图**上检测局部峰值。
默认仍为 `"analytic"`，旧场景保持解析门限行为；新的研究基线由主控显式启用实测 RD 检测。

该改动不把模型称为真实设备标定结果，不声称实现完整 CFAR、真实杂波统计或完整电磁散射。

## 主要变化

1. **窗口与噪声一致**。若复采样噪声 `E[|n|²]=pn`，未归一化 Hann 窗二维 FFT 单元的
   平均热噪声功率为 `mu=pn*sum(w_range²)*sum(w_doppler²)`。
   已知频率恰落在 FFT 单元中心的单频回波相干功率增益为
   `G=|sum(w_range)|²*|sum(w_doppler)|²`，处理增益为 `10log10(G/sum(w²))`。
   新模式的预期 SNR 使用这个窗口增益，不再直接套 `n_samples*n_chirps`。
2. **多波束最大值门限**。当前 RD 图对各波束取最大功率，不能直接采用单波束指数噪声门限。
   对模拟器的 B 个独立热噪声波束，`P(max<=x)=(1-exp(-x/mu))^B`；
   `threshold/mu=-ln(1-(1-Pfa)^(1/B))`，实现使用 `log1p/expm1` 保持低 Pfa 的精度。
3. **从图中检出**。门限判断和 3×3 局部峰选择只读取 RD 图，不读取物体位置。
   Doppler 邻域在 Nyquist 边界环绕，距离邻域不环绕。
4. **检出后再关联真值**。关联要求峰值获胜波束一致、在预期真值两单元内，且已知目标源
   在该单元的预计功率超过实测功率的一半。噪声峰不会仅因波束指向一个弱目标就继承其 ID。
   这是仿真真值匹配规则，不是真实雷达目标分类器。
5. **真实/测量量分开**。检出点的 `range`、`v_r` 来自 RD 单元坐标；
   只有关联到真值的检出点才包含 `range_true`、`v_r_true`。
   同时输出 `range_bin`、`doppler_bin`、`beam_index`，使标注能精确落到检出峰。
6. **未关联峰有记录**。噪声、人工杂波或未匹配峰保留为 `obj=-1`，不能全部当作目标点迹。
7. **分块无关随机流**。新模式按帧和波束派生独立噪声种子，内存预算改变 FFT 分块时不改变图像或检出结果。
8. **视场约束**。补采样机制现在拒绝后方及扫描波束支持范围外的物体，单波束配置取光轴中心。
9. 移除靠近量程边界时将回波频率强制夹到 `0.99*Nyquist` 的处理，避免移动真实峰值。

## 配置

```json
{
  "sensors": {
    "radar": {
      "detector": "rd_threshold",
      "pfa": 0.000001,
      "max_detections": 256,
      "mti_min_vr_mps": 0
    }
  }
}
```

`Pfa` 是局部峰筛选前的**每个 RD 单元、独立热噪声**概率，不是整幅图虚警概率。
它不适用于当前人工相干杂波；大量目标/杂波的邻域亦不能通过这个热噪声标定描述。
`max_detections` 仅截取功率最大的若干已过门限峰，属于显式输出上限。

## 输出约定

- `out.processing`：输入噪声、FFT 后平均单波束噪声、实际窗口增益、阈值、统计假设、限制。
- `detections[].snr_db`：实测峰功率/单波束平均 FFT 热噪声的 dB 比值（包含峰内噪声），
  不是直接测得的纯目标 SNR。
- `detections[].power`：与原始 RD 数组中对应单元完全相同。
- `detections[].associated_to_truth`：检出后的仿真源关联状态。
- 关联点的 `xyz` 为真值表面/补采样中心，标记 `xyz_basis="associated_truth_surface"`；
  未关联点用测量距离和波束方向估计三维位置，不宣称真实角度测量精度。
- 单 PRF 测得速度存在模糊，正号表示接近；`v_r_true` 保留未模糊值。
- 内部采用复数缓冲合成，沿旧实时 ADC 量程约定只输出正频率距离带；
  负频率区不再被错误描述成该复数合成缓冲的严格共轭镜像。

## 验证

运行：

```powershell
.\env\Scripts\python.exe -m unittest discover -s tests -p test_radar_realism.py -v
.\env\Scripts\python.exe -m simkit selftest
.\env\Scripts\python.exe tools/check_radar_realism.py --scene out/aviation_baseline_v2/airliner_parallel.json --out out/_tmp/radar_realism/airliner.json
```

八项专项检查全部通过：

- 独立复高斯噪声 FFT 平均功率与窗口理论一致；单频相干增益与理论一致。
- 八波束最大值，10 万组指数噪声 Monte Carlo 检查 `Pfa=0.01` 的边际虚警概率。
- 实测目标检出与保存的 RD 单元/峰值精确一致。
- 将目标功率降到可忽略、提高 Pfa 后，实测噪声峰不会标成飞机。
- 192 MB 与 0.001 MB 内存预算产生的 RD 数组、检出列表完全一致。
- 单波束位于光轴中心。
- 后方/视场外目标不再被补采样机制注入。
- Doppler 环绕与距离非环绕邻域行为正确。

原有内核 `selftest`（含 SAR 与轨迹子检查）最终 **ALL PASS**。

另以旧民航基线首帧生成专项检查结果，保存于独立 `out/_tmp/radar_realism/`：

- B777：一个关联目标峰；实测距离 22664.31 m，真值 22648.77 m，差异为距离单元量化。
  实测模糊速度 19.723 m/s，真值 19.427 m/s。
- SIERRA：没有关联目标峰，不强行生成正样本。
- 两场景各有 3 个未关联峰，来自 `clutter_density=0.02` 的人工相干杂波设置，
  不能将它们解释为纯热噪声 Pfa 实验。
- 1024×32 采样、48 波束的 Hann 窗处理增益 41.49 dB；`Pfa=1e-6` 的门限比约 17.6867。

## 尚未解决

- 冻结 CPI 期间的几何，不模拟距离迁移或 FMCW 距离/速度耦合；无真实扫描时间。
- 单返回的波束表示不能同时保留同一方向多距离散射体；补采样的角度/遮挡仍是近似。
- RCS 仍为面元近似或显式覆盖，不是材料/机型的实测散射数据库，可能依赖网格细分。
- Swerling II/IV 在旧实现中仍按 CPI 更新，并未实现逐脉冲去相关。
- 若启用旧 MTI 几何速度门控，它仍是简化处理；本轮民航实测 RD 基线将其关闭。
- 没有自适应 CFAR、杂波边缘处理、角度估计、目标分类或真实设备校验。

这些限制随 `processing` 元数据和实验报告保留，不用“自检通过”代替真实感验证。
