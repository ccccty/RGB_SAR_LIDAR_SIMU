# 2026-11-01 独立图像几何与 RD 质量检查

本轮将 `tools/check_aviation.py` 从文件/标定契约检查，扩展为读取两种独立渲染器实际导出的
实例 ID 和 camera-forward Z 深度，报告可测的图像几何一致性。仍不把结果称为真实传感器标定。

## 输入和坐标

- RGB：`raw/optical/NNNNNN.npz`，`instance_id`、`depth_z_m`。
- IR：`raw/ir_mwir/NNNNNN.npz`、`raw/ir_lwir/NNNNNN.npz`，同样的实例/深度键。
- `instance_id=-1` 为背景；目标 ID 从雷达三维框或红外对象表映射到稳定目标名。
- 比较声明为同一个共位置、共视场的 primary view。不同外参/视场的模态需要先重投影，
  不能把本检查器的像素比较直接用于任意安装布局。
- IR 使用覆盖率超采样，其 ID/depth 可能取最近子样本；RGB 与 IR 边缘支持不必逐像素完全一致。

## 指标与判定

每一帧、每个 RGB/IR 对记录：实际实例像素数、像素中心质心差、投影实例 bbox IoU、
mask IoU、交集/较小 mask 面积，以及共同有效实例像素上的深度绝对差中位数与 P95。

只有两个原始 mask 均有至少 8 像素、同一网格尺寸且未碰到图像边界，才进行默认阈值判定：

- 质心差不超过 3 个 RGB 像素。
- 实例 bbox IoU 不低于 0.1；mask 重叠指标先报告，不因超采样覆盖不同简单强制等于 1。
- 共同像素的深度差中位数不超过 `max(5 m, 0.002 × 实际深度)`。

阈值是显式的工程 QA 假设，不代表仪器指标；可通过生成配置根部 `geometry_registration`
覆写，对应键见 `DEFAULT_REGISTRATION`。实际 smoke 指标远低于阈值，没有为样本放宽阈值。

状态分开处理：

- `measured_within_tolerance`：有充分支持，独立几何度量通过。
- `insufficient_support`：小于采样支持阈值或某个模态没有目标像素；不当作自动失败。
  当任意一侧为空时，质心/IoU/深度误差为 `null`，不会虚报“0 像素配准误差”。
- `different_sampling_report_only`：转换到归一化视场后报告，重采样不创造信息，不硬判。
- `edge_clipped_report_only`：目标被图像边缘截断，仅描述观测结果。
- `unavailable`：没有独立几何数据。v2 全部未导出时兼容读取，但不能宣称图像内容已验证。
- `failed`：充分支持的图像对超阈值；检查器返回非零。

若配置声明 `optical.export_geometry`，或该运行已有任意 RGB/IR 几何缓冲，则后续缺失 NPZ
是错误，不能被当成小目标漏采。目标实例下深度为 NaN/Inf/非正数、网格形状错误亦失败。

## RD 与配对表

增加了实测检测与保存的浮点 RD 数组的一致性检查：测量值位于声明单元、该单元是局部峰、
超过保存门限、峰值功率与数组一致；真值径向速度按单 PRF 周期折叠后与测量速度比较，
允许半个 Doppler 单元的量化误差。旧解析检测仍按旧连续速度约定检查。

未检测到目标仍是合法结果。`radar_unassociated_detections` 分开统计，可能包含人工杂波、
热噪声或未匹配峰，不笼统称为热噪声虚警。

`pairs.csv` 增加 `rgb_raw`、`mwir_raw`、`lwir_raw`、各 IR 几何检查状态、目标检出数及未关联检出数。
`quality.json.registration.pairs` 保留逐帧实际数值和状态原因。

## 验证

```powershell
.\env\Scripts\python.exe -m unittest discover -s tests -p test_quality.py -v
.\env\Scripts\python.exe tools/check_aviation.py out/aviation_realism_smoke_v2
.\env\Scripts\python.exe tools/check_aviation.py out/aviation_baseline_v2
```

11 项专项测试全部通过，覆盖实际相同缓冲、故意平移 8 px、缺失几何文件、空/单像素目标、
不同分辨率、边界截断、实例下无深度、深度偏差、v2 兼容、速度模糊合法情况与错误 RD 单元。

真实集成 smoke（B777 交叉，两帧）结果：

- 两帧 × MWIR/LWIR，共四对均为 `measured_within_tolerance`。
- RGB 目标实例 216 px，IR 238–239 px。
- 质心差 **0.093–0.184 px**；bbox IoU **0.9783**。
- mask IoU **0.9038–0.9076**；交集覆盖较小 mask 的全部像素。
- 共同目标像素深度绝对差中位数 **0.107–0.121 m**，P95 **1.28–1.41 m**。
- 雷达目标检出 2/2 帧，未关联峰共 6 个；实际 bin、局部峰、门限和速度模糊检查通过。
- v2 六组旧样本保持通过，同时维持 `not independently validated` 图像内容状态。

正式 v3 全量短序列结果由主控汇总；这些几何通过结果不等于跨波段辐射/视觉真实性或真实仪器配准验证。
