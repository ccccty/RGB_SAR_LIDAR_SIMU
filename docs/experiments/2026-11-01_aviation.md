# 2026-11-01 民航机载基线变更与实验记录

日期按 Asia/Shanghai 记录。本轮不自动提交、不推送。

## 需求确认

- 民用航空博士课题，观测飞机观察空中的另一架飞机。
- 距离 20 km 以上，任务为检测、持续跟踪、区分所选有人机/无人机模型。
- 首批模态为 RGB、红外、雷达 RD；暂无真实样图或设备参数。
- 用户授权联网寻找公开模型，并要求保留以后上传仓库所需的可复现记录。

## 修改与原因

| 文件 | 变更 | 原因 |
|---|---|---|
| `simkit/plan.py` | 独立观测轨迹；从轨迹计算平台速度；导出目标速度 | 原平台场景目标基本静止；批次内差分在单帧分块/片段边界错误 |
| `simkit/observations.py` | 标定、世界状态、时间与假设清单 | 将真值、成像坐标、有效观测和未实现项分开 |
| `simkit/dataset.py` | 采用规划器速度；写逐帧观测和原始 RD | 支持可追溯跨模态配对和浮点数据分析 |
| `simkit/optical.py`、`blender/render_optical.py` | 根据每帧世界坐标更新远裁剪面 | 局部包围盒漏掉目标平移，导致远目标有标签无图像 |
| `simkit/radar.py` | 低于检测门限仍合成回波；背景相对速度；小目标替代返回不继承地面功率 | 避免人为擦除弱目标、零多普勒背景及错误强回波 |
| `simkit/labels.py` | 分别导出真实/模糊径向速度 | 单 PRF 模糊后的速度不能作为运动真值 |
| `tools/fetch_aviation_models.py` | 官方下载与锁定哈希 | 资产可复现、上游改变可检测 |
| `tools/prepare_aviation_models.py` | 米制几何与转换记录 | 不将 NASA 展示用模型单位直接当米 |
| `tools/build_aviation.py` | 六场景、禁止覆盖、构建清单 | 防止混批，并记录生成时的实际源码 |
| `tools/check_aviation.py` | 配对表、几何/文件/速度检查 | 用保存结果验收数据契约，明确未验证图像内容配准 |
| `tests/test_aviation.py` | 七项回归检查 | 覆盖真实故障与独立物理/投影约束 |

## 实验 A：首轮失败样本

- 目录：`out/aviation_baseline_v1/`（不进 Git）。
- 命令：`python tools/build_aviation.py --out out/aviation_baseline_v1 -n 4 --dt 0.5`。
- 两模型 × 三种运动关系 × 四帧，共 24 个时刻。
- 观察到 RGB 飞机缺失而投影标签存在。定位：远裁剪距离用局部模型包围盒计算，
  对平移到约 22 km 的目标未覆盖；每帧世界几何更新后重算裁剪范围。
- 观察到空对地背景下飞机雷达 SNR 异常偏强。定位：波束漏采小目标时，
  补回波将地面功率相加后改成目标 ID；改单返回模型为较近返回替代，不混用功率。
- **本轮目录仅保留故障证据，不能用于训练。**

## 实验 B：修复后重生成

- 目录：`out/aviation_baseline_v2/`（不进 Git），避免覆盖实验 A。
- 命令：`python tools/build_aviation.py --out out/aviation_baseline_v2 -n 4 --dt 0.5`。
- 实际命令、Python/numpy、Git 基线与脏状态、源码/配置/资产哈希保存于根目录 `build_manifest.json`。
- 质量检查：`python tools/check_aviation.py out/aviation_baseline_v2`。
- 六组全部完成，共 24 个时刻；每个时刻含 RGB、MWIR/LWIR 原始计数及预览、RD PNG/浮点功率。
- 所有质量检查通过，无缺失文件；实际斜距范围约 22.037–22.649 km。
- 标定矩阵与向量公式的最大投影差约 `1.03e-12 px`；这是几何契约检查，**不是图像内容配准误差**。
- B777 三组均为 4/4 帧有雷达检测；SIERRA 三组均为 0/4 帧达到检测门限。
  这些仅为未标定研究参数下的结果，不代表真实探测能力。
- B777 同向第一帧的检测 SNR 从故障样本的 85.99 dB 降为修复后的 41.04 dB，
  展示了地面功率误归属的影响；修复后的绝对数值仍待实测校准。
- 修复后的 RGB 已能看到飞机；检查六场景首帧的裁剪放大对照图，
  小型无人机和 MWIR 的信号较弱，保留原样。
- 结果摘要（含源码/资产哈希和运行环境）见
  [`2026-11-01_aviation_results.json`](2026-11-01_aviation_results.json)。
- 预览命令：`python tools/aviation_preview.py out/aviation_baseline_v2`；
  输出 `preview.jpg`（不进 Git），64×64 原像素裁剪按最近邻放大四倍，未增强信号。
