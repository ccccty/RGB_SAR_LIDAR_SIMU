# 2026-11-01 红外与高度大气真实性改进

本记录对应民用航空机载观测研究。修改不等于真实设备标定，也不提供具体设备的探测距离结论。

## 已实现的修正

1. **高度剖面大气（显式启用）**：新增 `simkit/atmosphere.py`，气溶胶、干气体、水汽和雨项
   使用独立尺度高度。沿直线光路解析积分消光，按 Beer–Lambert 定律计算透过率。
   原来将整个 20 km 高空斜程乘海平面系数的做法可通过新配置替代。
2. **路径自发辐射**：IR 路径按分层温度计算 `T_near*(1-T_segment)*B(T_segment)` 累加，
   保留大气既消光又发射的能量关系。用 Planck 查找表避免每像素逐波长逐层计算。
3. **逐像素距离**：先栅格化源表面辐射，再由每像素深度重建光路；不再把一个巨大地面三角形
   的质心距离当成整块面的路径长度。减少由三角剖分产生的假分区。
4. **局部热分区**：明确配置局部热通量或温度，不将发动机和机身强制设为同温。
   面元能量平衡可在新大气配置下使用当地高度的环境温度。
5. **稳定表面纹理**：默认改为物体局部坐标下的平滑固定温度变化，同一表面不会因帧噪声种子
   改变而闪烁，MWIR/LWIR 共用同一温度纹理。旧逐帧纹理仅能显式选择。
6. **面积采样**：新 `coverage` 模式用每轴 2–4 个子样本后按面积平均，禁用“没有采样到目标
   就强行填满一个像素”的旧做法；返回各实例实际子样本覆盖率。
7. **近面裁剪**：跨越相机近裁剪面的地面三角形先做几何裁剪，不再整面丢弃而形成空洞。
8. **辐射与计数修正**：Planck 波段积分改梯形积分（300 K 的 8–12 µm 为约 38.50 W/m²/sr）；
   所有路径下的 16-bit 输出均饱和裁剪，避免高增益且未启用 NUC 时整数回绕。

## 配置示例

```json
{
  "atmosphere": {
    "profile": "exponential",
    "reference_altitude_m": 0,
    "temperature_at_reference_c": 20,
    "temperature_lapse_k_per_km": 6.5,
    "minimum_temperature_k": 216.65,
    "aerosol_scale_height_m": 1200,
    "molecular_scale_height_m": 8000,
    "water_scale_height_m": 2000,
    "rain_scale_height_m": 2000,
    "emission_steps": 12
  },
  "ir": {
    "samples_per_axis": 2,
    "subpixel_mode": "coverage",
    "texture_mode": "surface",
    "texture_sigma_c": 0.6,
    "texture_scale_m": 1.0,
    "texture_seed": 123
  }
}
```

这些尺度高度与温度剖面是可配置研究假设，不是通过气象探空拟合的结果。地面 weather 能见度
作为参考高度的总可见光消光；其中默认分出 0.011/km 作为分子项，其余作为气溶胶项，
不会在海平面把 Rayleigh 项重复加到 weather 总消光之上。IR 的干气体/水汽/气溶胶项
沿用现有经验系数并各自衰减。`extinction_at_reference_per_km` 可显式覆盖某一波段总系数，
该覆盖按单一气溶胶尺度积分，避免假装已知未知的分子比例。

未写 `atmosphere.profile` 时保留均匀大气模型。旧采样模式默认 `legacy` 以兼容历史场景，
新研究场景应显式配置 `coverage`。`ir.texture_mode="legacy_per_frame"` 可复现旧闪烁纹理。
Planck 积分、逐像素距离、近裁剪和计数饱和的修正直接适用于旧配置。

热区放在目标对象的 `thermal_regions`：

```json
{
  "thermal_regions": [
    {
      "material_names": ["EngineMetal"],
      "bounds_local_m": [[-20, -12, 0], [20, 12, 5]],
      "heat_flux_w_m2": 1500
    },
    {
      "group_names": ["exhaust"],
      "temp_c": 150
    }
  ]
}
```

`material_names`、`group_names`、`bounds_local_m` 可任选或组合，组合时取交集；
坐标是模型完成尺度归一化后、旋转和平移前的局部米制坐标。
`heat_flux_w_m2` 替代匹配面的材质内部热通量，先于稳态求解；`temp_c` 是最终温度覆盖，
优先于整对象 `temp_c`；后定义的重叠热区覆盖先定义的热区。
数值是显式假设，不从 RGB 颜色猜测。未实现热惯性、机体传导、排气羽流或完整发动机热模型。

## 公共 API 与深度约定

- `atmosphere.path_transmittance(origin3, endpoints[...,3], cfg, modality)`：可见光/IR 共用。
- `atmosphere.optical_depth(...)`：同一路径的消光积分。
- `atmosphere.sky_endpoints(origin3, directions[...,3], cfg)`、`sky_transmittance(...)`：背景路径代理。
- `atmosphere.path_emission(origin3, endpoints[...,3], cfg, band_um, modality)`：热路径辐射。
- `atmosphere.temperature_k(altitude_m, cfg)`：声明的温度高度剖面。
- `ir.render` 仍返回前向相机 Z 深度，不是欧式距离；多子样本时返回像素内最近子样本的 Z，
  在 `sampling.depth_rule` 声明。`instance_coverage` 是物体 ID 到浮点覆盖率图的字典。

背景向上以 80 km 大气顶为终点，向下以参考高度平面为终点，近水平路径默认截为 200 km。
这是平面地球近似，不包含曲率、地形遮挡或复杂云体。天空辐射仅是有限路径的 LTE 发射近似，
不宣称完整大气辐射传输。

## 集成前独立审查：模型朝向、热区与 RGB 深度

对主控 `config('airliner','crossing',realism=True)` 和无人机配置做了单独几何审查，
没有覆盖公共数据目录，也未重跑所有测试。

- 修正前的模型局部 XY 面心散点图中，B777 与 SIERRA 都是机鼻朝 **−X**，尾部朝 **+X**。
  `prepare_aviation_models.py` 原来使用 `−π/2` 的 Z 旋转，却声明 +X 为前方，
  会导致沿速度设置 yaw 后飞机倒着飞。主控据此将转换改为 `+π/2`，并统一原生 GLB 渲染变换。
- 修正前的 B777 热区选中约 1400/4314 个面（32.45%），总面积约 900 m²，
  包含大量机翼 PaintM；SIERRA 热区选中 1238/4872 个面（25.4%），还包含玻璃和橡胶。
  这些是空间范围过宽，不是实际发动机热区。
- 按 XY 翻转后的 +X 机鼻坐标推荐更窄的热源区域，并与 `material_names=["MetalM"]` 取交集：

| 模型/部位 | bounds_local_m | 翻转原模型面心后的匹配情况 |
|---|---|---|
| B777 一侧后部喷口金属 | `[[2,-11.5,0],[5,-8.5,3]]` | 15 面，7.11 m² |
| B777 另一侧后部喷口金属 | `[[2,8.5,0],[5,11.5,3]]` | 8 面，5.31 m² |
| SIERRA 后部推式发动机金属 | `[[-0.8,-0.2,0.4],[-0.4,0.2,1.0]]` | 349 面，0.596 m² |

表中计数基于修正前已经抽稀的模型再翻转面心；重新转换后顶点聚类网格的原点可能稍有变化，
最终计数需在新资产生成后复核。选区属于人工几何标注，热通量仍是研究假设，不能当作实测热场。

证据图和统计保留于忽略目录 `out/_tmp/infrared/airliner_heat_regions.png`、
`uav_heat_regions.png`、`heat_region_review.json`，文件标题明确为局部面心而非渲染热图。

另审查了 `simkit/optical_sensor.py` 的深度重建：离轴且横滚 17° 的小图调用产生有限透过率，
