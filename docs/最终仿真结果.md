## 四、本轮修掉的两个真实 bug

远距离场景曾经出现「目标框 = 整幅画面、渲染里看不见目标」，根因两处：

1. **Blender 默认裁剪距离 0.1–100 m**。1.5 km 外的目标被整体裁掉，画面只剩天空，
   而标签仍按投影算出，于是框覆盖全图。已改为按场景实际距离设置 `clip_end`。
2. **Blender 分支完全没走 `scale`/`decimate`**。Global Hawk 按原始 417 m 渲染而不是
   39.9 m；同时重心平移后 bbox 没跟着更新。已抽出 `scene.prepare_mesh()`，
   让 numpy 物理世界与 Blender 渲染共用同一条网格准备路径。

修复后几何自洽：1.49 km / 3.5° 视场 / 640 px 下，44 m 翼展应占约 155 px（320 px 宽时），
实测 155×87 px。

## 六、已知局限（未解决）

1. 中波/长波红外 AGC 预览图相关系数 0.995+：两者都受同一表面温度主导，
   波段差异在 8-bit 预览上被拉平。看真实差异要用 16-bit 原始计数——
   平均绝对差 46–63 counts（1 count ≈ 3.8 mK，即约 175–240 mK），
   单像素最大 1.7 K，主要出现在目标边缘与高温部位。
2. 雷达 RCS 仍是几何 PO + `rcs_db` 覆盖值，不是实测；无人机 +1.5 dBsm 是合理占位值。
3. 海面为六正弦叠加，无白冠、无破碎波；海气温差未建模。
4. 光学只按 6 张实拍照片标定了天空亮度，地面与阴影未单独标定。
5. 天气只有晴/阴/雨三档，缺雾、雪、沙尘。
