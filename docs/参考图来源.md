# 参考图来源（assets/ref）

全部来自 Wikimedia Commons，许可逐条记录在 `assets/ref/provenance.csv`。
**用途**：只作"实拍对照"——校准材质反照率/发射率量级、检查仿真图像的对比度方向是否合理。
不进入训练集，不进数据集交付物。

## 下载方式（可复现，需联网）

```powershell
& .\env\Scripts\python.exe tools\_fetch_ref.py    # 红外 5 张
& .\env\Scripts\python.exe tools\_fetch_ref2.py   # 光学 6 张
```

脚本只读 Commons API 的 `imageinfo`，只下载 ≥700 px 的 JPEG/PNG，自动写许可与作者。
CC BY-SA 的图如要再分发，必须保留署名与相同方式共享。
