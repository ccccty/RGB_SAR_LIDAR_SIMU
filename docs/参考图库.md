# 参考图库与实拍参数

> 目的：给 10 类、60 个渲染模型（assets/models 下 52 个分类模型 + 根目录 8 个杂项 .obj）建立实拍对照，并从照片里取出可以直接驱动渲染的参数
> （目标色/有效反照率、纹理能量、天空统计、相机噪声），再和 `simkit/materials.py` 的
> 现值比对，给出**建议值**（只写进 `configs/refs_params.json`，不改 `materials.py`）。

- 图库：`assets/refs/`（10 类，共 90 张下载、58 张入库），来源全部为 Wikimedia Commons，
  许可逐张记录在 `assets/refs/catalog.json`。
- 参数：`configs/refs_params.json`（每类聚合值 + 每张图的原始测量）。
- 工具：`tools/fetch_refs.py`（下载/许可）、`tools/extract_refs.py`（分割与测量、对比、报告素材）。
- 下载约束：`iiurlwidth=1024`，单张 36–451 KB（全部 < 500 KB），只收 JPEG/PNG 照片，
  无许可元数据的文件直接跳过。

## 1. 两类用途，不要混用

| 用途 | 需要什么图 | 本图库对应 | 能得到的参数 |
|---|---|---|---|
| A 材质与纹理 | 近距、目标占画面 5% 以上、侧面或 3/4、光照清楚 | 主体（A 类 33 张 / 中间 17 张） | 涂装颜色、有效反照率、纹理高频占比、拉普拉斯方差 |
| B 退化链 | 远距、目标几十像素、真实传感器噪声/PSF | 只有 8 张（B 类），且不是专门的退化数据 | 只能做目标占比/天空噪声的**定性**对照 |

`configs/refs_params.json` 的每一类都有 `usage` 字段给出 A/B/中间张数，每张图另有
`usage` 标签。**不要把这两类混用来定色**：B 类样本的目标区太小，中位色基本是背景混合色。

不在本图库、也不该由它承担的：AOT（8 bit 灰度，目标几十像素）、Anti-UAV410（640×512 长波红外，
< 20 px）属于退化链参考；VisDrone 的 10 类里没有飞机；MSTAR / SenSiAC 是地面车辆 SAR/IR；
公开的真实 SAR 飞机切片只有约 4k（SAR-AIRcraft-1.0 / SARDet-100K）。20 km 机载工况没有
可直接对标的真实测试集，本图库只回答「可见光下这个目标长什么样」。

机型选择上刻意避开了泛词：军用飞机用 F-15 / F-16 / Su-27 / F-4 / Rafale / Fokker Dr.I，
民航用 737 / 747 / 777 / A320 / ATR 72，直升机用 OH-58 / UH-60 / AH-64 / Mi-8，

## 2. 方法（可复现、可审计）

1. **下载**：Commons `generator=search` + `gsrnamespace=6`，机型级检索词；照片类目优先用
   `deepcategory:"Aircraft in flight"` / `"Helicopters in flight"` 过滤，
   标题命中 diagram/orthograph/cockpit/interior/map 的直接丢弃；同类里近似重复的标题只留一张。
   每张图记录标题、原始尺寸、许可、作者、SHA-256。
2. **目标区**：不训练分割模型。先用「从顶边洪泛 + 色度约束」得到天空（蓝/中性、拒绝绿色植被），
   再用两种假设做目标框：(A) 边框背景模型，k-means(8) 拟合边框+天空颜色，取离背景色最远的最大连通域；
   (B) 天空补集，非天空区域的最大连通域（适合目标占满画面、边框全是目标的近景）。
   两个候选按边缘贴合度、紧致度、天空色占比打分，取高分者做**外接框**；框内再去掉天空像素。
   目标色取框内非天空像素的中位数（含背光面，这是「渲染该有多亮」而非「漆的物理反射率」）。
   自动框明显错误时在 `tools/extract_refs.py` 的 `REVIEW` 表里剔除，
   `catalog.json` 里对应记录 `manual_box` / `accepted` / `review`。
3. **反照率（去光照）**：albedo_linear = median_target(L_linear) / (k × median_sky(L_linear))。
   比值与曝光无关（同一张图），k 把直射/漫射比折成一个数：晴天 k=4.0（可见面中位照度约为水平总辐照的
   60%）、薄雾/高云 k=2.0、均匀阴天 k=1.2（此时天空辐亮度本身就是照度尺度）。
   天空不合格（暗、偏绿、过曝、几乎无天空）时不出反照率，标 `albedo_valid=false`。
4. **纹理**：目标区 Hann 窗二维功率谱，hf_ratio = ΣPSD(≥0.25 cyc/px) / ΣPSD(0.02–0.5)；
   拉普拉斯方差在 DN² 下统计。
5. **天空/背景**：天空掩膜内 sRGB 亮度均值/标准差；径向功率谱在 0.02–0.42 cyc/px 上做 log-log 拟合得斜率。
6. **噪声**：天空区 4 邻域拉普拉斯残差的稳健 σ（MAD，退化时用 95% 截尾平均绝对差），/√1.25 得到 DN。
   JPEG 会吃掉高频，所以这是**下界**。
7. **聚合**：每类取通过质量门的样本中位数；质量门 = 天空合格 + 非逆光 + 非天空污染 + 目标区够大。
   置信度 high（≥2 张晴天样本）/medium/low/none 写进 JSON，低置信时建议值向现值收缩。

## 4. 和 `simkit/materials.py` 的差

现状：`scene.py` 对每个对象都默认 `mat="painted_metal"`，随场景文件也没有覆盖，
Blender 端 `make_material()` 直接把它写成 Principled BSDF 的 Base Color
（`albedo=(0.22,0.24,0.28)`，roughness 0.25，metallic 0.1）。所以**10 类、60 个 .obj 模型共用同一个
中灰**。实测每类中位数（见第 0 节）相对它的倍率：

- 变亮：民航飞机 **2.6×**、固定翼无人机 1.15×。
- 变暗：军舰 0.56×、民用船舶 0.36×、旋翼无人机 0.41×、杂项 0.47×、军用飞机 0.66×、
  地面车辆 0.26×、军用地面车辆 0.11×、直升机 0.05×（逆光偏差，见限制）。

按通道看，唯一稳定偏离的是**军舰**：实测 R>G>B（0.183/0.135/0.096，冷灰偏暖），
而现值 B 通道最高（0.22/0.24/0.28，偏冷蓝）——颜色方向反了。

另外两处不是 albedo、但同样来自实拍对照：

- **粗糙度**：照片里涂装是宽而低对比的高光（天空 std 只有 10–38 DN），
  `painted_metal` 的 roughness 0.25 + metallic 0.1 会渲染出偏塑料的窄高光。
  建议哑光涂装 roughness 0.45–0.6、metallic 0.0–0.05（仅 `metal_bare` 保持高金属度）。
- **纹理**：目标区高频功率占比 0.012–0.043，而我们没有任何贴图/程序化细节，渲染出来是「干净色块」。
  按参考，加 1–5% 对比度的程序化 albedo/roughness 变化（蒙皮分块、油污、锈迹）就够了，
  不需要照片贴图。

天空与噪声：

- 实测天空均值 77–218 DN、std 10–38、功率谱斜率 −1.7…−2.7。现有解析渐变天空
  （zenith 0.030/0.075/0.220、horizon 0.52/0.60/0.72）没有云结构，斜率远陡于实拍；
  只有纯天顶视野可以接受。用 `assets/hdri` 的 HDRI 天空更接近实拍统计。
- 实测天空高频 σ 0.1–10 DN（JPEG 下限），而 Cycles 渲染默认开降噪，RGB 图**没有相机噪声**。
  这是「干净合成集」与「实拍外观」之间最大的一处差异，是否补噪声取决于数据集定位。

## 5. 按这个参考，渲染最该改什么（按优先级）

1. **把单一 `painted_metal` 拆成按类别的 Base Color**（收益最大）。
   不动物理库也能做：在场景/资产层给每类注入 albedo，或新增
   paint_white(0.52,0.53,0.57)、navy_grey(0.19,0.15,0.12)、olive_drab(0.11,0.10,0.07)、
   dark_composite(0.09,0.10,0.11) 四个变体再按类引用。优先改民航飞机（2.6×）与军舰（颜色方向反了）。
2. **白/浅色载具（客机、邮轮、白色无人机）单独给高反照率**，深色军用目标给低反照率；
   否则同一张图里白机身和灰舰体不可能同时正确。
3. **roughness/metallic 调成哑光**（见第 4 节），让高光变宽、变弱。
4. **加低幅度程序化纹理**（高频占比 0.01–0.04 量级），先解决「色块感」，不追求照片级贴图。
5. **天空用 HDRI 或给渐变天空加云层统计**；把每场景的 sky_mean/sky_std/psd_slope 记进
   导出元数据，方便和实拍对照。
6. **决定是否加相机噪声/PSF**：要贴实拍就加（0.1–10 DN 量级、轻微镜头模糊）；
   要干净合成集就在文档里写明差异，不要两头都想要。
7. **补图库缺口**：地面车辆只有高尔夫一种车型、军用地面车辆只有 4 张、杂项缺灌木/巡视器、
   直升机样本全是逆光。下一轮按「A 类、目标占画面 ≥ 10%、晴天、侧面」补 3–5 张/类，
   参数会明显更稳。

## 6. 复现

```powershell
$env:PYTHONPATH = (Get-Location).Path   # 在仓库根目录下执行
.\env\Scripts\python.exe tools\fetch_refs.py --target 9     # 下载（可重跑，幂等）
.\env\Scripts\python.exe tools\extract_refs.py --sheet       # 测量 + 接触表 out/refs_review
```

- 想换机型/补角度：改 `tools/fetch_refs.py` 顶部的 `CATEGORY_QUERIES`，重跑即可（已有文件不会重复下载）。
- 想改某张图的裁剪框或剔除：改 `tools/extract_refs.py` 的 `REVIEW` 表（键是文件名前缀），
  重跑后 `catalog.json` 会记录 `manual_box` / `accepted` / `review`。
- 全部失败都会写进 `catalog.json` 的 `errors`，不会中断（本轮 0 条错误、21 条跳过）。

## 7. 已知限制

- **绝对标定**：没有曝光信息，只能用「同一张图里天空/目标亮度比」去掉曝光；k 的取值带来约 ±35%，
  叠加 JPEG 色调曲线与逆光样本，单张值的可信区间更宽。**跨类别比较只在 1.5× 以上的差异上可信。**
- **分割是框内减天空**，不是像素级掩膜。目标与背景同色（白机身+白天空）时，中位色会混入少量背景。
- **直升机/地面车辆/军用地面车辆样本少且光照差**，置信度 low，建议值已向现值收缩，仅供参考。
- **杂项只有隔离墩和围栏**，不能代表灌木/巡视器/小型旋翼机。
- **catalog.json 里 accepted=false 的图仍在磁盘上**（审计用，不参与统计），统计只用 accepted=true。
