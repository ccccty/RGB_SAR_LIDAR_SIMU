# 民航机载多模态基线

> 后续已实现源材质、共享网格清理、高度大气、局部热源、RGB 传感器/曝光和独立几何配准。
> 当前推荐入口见 [真实性升级 v3](真实性升级_v3.md)。本页保留首轮 v1/v2 的历史假设与结果，
> 下文“未实现”描述不应代替 v3 的当前状态。

本轮范围：飞机观察空中飞机，20 km 以上，RGB + MWIR/LWIR 红外 + 雷达 RD。
任务为目标检测、持续跟踪，以及所选飞机/无人机模型的类别区分。

当前交付是**几何、时间和数据契约基线**。传感器、材质与环境尚无实测标定，
不能据此宣称真实设备探测距离，也不能把这组 QA 短序列作为正式论文训练/测试集。

## 1. 新增能力

- `clip.observer_trajectory` 与 `clip.trajectory` 分别定义观测飞机和目标飞机的轨迹。
- 一个基线场景仅允许一个带标签目标，避免旧规划器将多个目标放在同一条轨迹上。
- 平台速度从本片段轨迹函数求导，不再从当前批次的相邻帧估算；单帧分块也保持正确。
- 每帧输出标定矩阵、世界状态、稳定目标 ID、真实距离和正闭合径向速度。
- RD 除 PNG 外保留浮点功率和物理坐标轴；真实速度与单 PRF 模糊后的速度分别记录。
- 生成器拒绝覆盖已有输出目录，根目录清单记录配置、源码和资产哈希。

## 2. 模型来源与尺度

模型来自 [NASA Airborne Science Program 官方三维模型库](https://airbornescience.nasa.gov/3d-models/)。
原始 GLB、来源 URL、SHA-256 分别由下载器获取并校验；索引见
[`assets/aviation/sources.json`](../assets/aviation/sources.json)。

| 角色 | 模型 | 研究尺度 |
|---|---|---|
| 有人机代表 | B777 - LaRC | 翼展归一化 60.9 m；具体变型仍需核实 |
| 固定翼无人机代表 | SIERRA - ARC | 翼展归一化 6.1 m |

SIERRA 的 20 ft 翼展可参考 [NASA SIERRA 官方说明](https://airbornescience.nasa.gov/aircraft/SIERRA_-_ARC)。
转换器记录原始尺寸、尺度因子、转换后尺寸、材质名、Blender 版本和 OBJ 哈希。
当前转换约定为 Z 向上、+X 为模型前向；正式实验前仍需对具体模型检查前后方向与轮廓。

[NASA 媒体使用指南](https://www.nasa.gov/nasa-brand-center/images-and-media/)。

## 3. 从干净环境复现

以下命令均在项目根目录的 PowerShell 执行。需要 Python + numpy 和 Blender；
`env` 和 `third_party/blender` 是本机安装路径，不随仓库发布。

```powershell
# 1. 下载并核验官方模型（上游内容变更时拒绝静默使用）
.\env\Scripts\python.exe tools/fetch_aviation_models.py

# 2. 转成仿真共用的米制几何
.\third_party\blender\blender.exe -b --factory-startup -P tools/prepare_aviation_models.py

# 3. 核心与新增回归检查
.\env\Scripts\python.exe -m simkit selftest
.\env\Scripts\python.exe -m unittest discover -s tests -v

# 4. 两模型 × 同向/交叉/相向，各 4 帧；每次必须使用新的输出目录
.\env\Scripts\python.exe tools/build_aviation.py --out out/aviation_baseline_v2 -n 4 --dt 0.5

# 5. 检查并生成配对表、质量报告
.\env\Scripts\python.exe tools/check_aviation.py out/aviation_baseline_v2

# 6. 可选：需 Pillow，生成明确标注放大倍率的对照图
.\env\Scripts\python.exe tools/aviation_preview.py out/aviation_baseline_v2
```

`-n 4 --dt 0.5` 仅为流水线与几何 QA，采样过低、片段过短，不能用于高速跟踪性能结论。
需增加时长/帧率时，例如 `-n 120 --dt 0.05`，仍应换一个全新输出目录。
增加帧数不会增加模型实例或独立场景的数量。

可用 `--only airliner_crossing` 单独生成一类关系，`--config-only` 只写配置和构建清单。
`--sensors ir,radar` 可进行无 Blender 渲染的计算检查，但完整质量检查要求 RGB 也已生成。

## 4. 输出契约

```text
aviation_baseline_v2/
  build_manifest.json             命令、源码哈希、Git 基线/脏状态、软件版本、资产和配置哈希
  airliner_parallel.json          本次实际使用的场景配置
  airliner_parallel/
    observations/000000.json      时间、目标 ID、世界状态、标定矩阵、采集假设
    images/optical/               RGB
    images/ir_mwir/               中波红外 16-bit 原始计数
    images/ir_lwir/               长波红外 16-bit 原始计数
    images/ir_preview_*/          8-bit 显示预览
    images/radar/                RD 显示图
    raw/radar/000000.npz          浮点功率、距离轴、闭合速度轴
    labels/                      各模态标注；雷达含真实/模糊速度和坐标轴
    frames.json                  片段/帧索引
    pairs.csv                    检查器生成的同帧配对表与各模态观测状态
    quality.json                 检查结果和适用范围
```

RD 原始数组为 `[velocity_bin, range_bin]`，PNG 与其同向。
`closing_speed_mps` 正值表示接近；图中速度为单 PRF 模糊后的速度，
`observations.objects[].closing_speed_mps` 是真实几何闭合速度，不能直接混用。

相机坐标为 X 右、Y 下、Z 前；`world_to_camera` 为 4×4，`K` 为 3×3。
投影坐标使用连续图像边界坐标，主点 `(W/2,H/2)`；用于其他像素中心约定时须转换。

`timestamp_s` 是片段局部时间；`sequence_timestamp_s` 是全局帧时间。
雷达积累区间以图像参考时间为中心；负的片段起始时间表示使用解析轨迹的起始前延拓。
目前相机曝光时长仅记录，未实际积分；RD 在参考时刻冻结几何，未模拟积累期距离迁移。

## 5. 哪些检查证明了什么

- 相机矩阵重投影与独立的向量投影一致：验证坐标和标定契约。
- 距离时间导数与相对速度一致：验证双机运动关系。
- 单帧分块/片段边界不改变速度：防止并行生成时的径向速度错误。
- 雷达输出真值速度与三维运动一致，RD 物理坐标轴单调且数组有效。
- 检查各模态文件、标签和配对完整性。

**没有证明** RGB 与红外的真实图像轮廓逐像素一致，也没有证明实测传感器真实性。
这两个状态显式写入 `quality.json`，不能用“标注框相同”代替图像配准验收。
`*_raster_visible` 当前仅为既有渲染器的可见性判据，尤其 RGB 使用几何射线检查，
并非探测概率或实际实例掩膜测量；`pixels=0` 也不能独立解释为物体不可见。

## 6. 当前仍待完成

1. **外观与物理属性**：保留原模型分部件材质/纹理，补发动机局部热源；
   当前渲染路径仍使用单一 painted-metal 预设，原 GLB 材质虽保留在源资产中，并未用于成像。
2. **高空大气**：当前仍将经验消光系数用于整个斜程，未沿高度剖面积分。
3. **雷达真实性**：单返回近似、粗面元散射、背景模型和检测过程仍需校准；
   不得用这组输出推断真实设备能在 20 km 探测某一尺寸飞机。
4. **时域成像**：曝光积分、RD 积累期间运动、扫描时序与传感器不同步。
5. **真实图像配准**：独立实例掩膜/深度输出和渲染内容一致性检查。
6. **跟踪与数据划分**：更长序列、多目标、遮挡/漏检/重现、独立模型/场景分组切分，
   以及真正运行的检测/跟踪基线。当前没有训练或验证跟踪模型。

两种模型与三个运动关系会有明显的身份/速度偏差。正式训练时必须增加模型实例并平衡运动条件，
避免分类器只学到“快的是有人机、慢的是无人机”。

历史问题与本轮结果见 [`experiments/2026-11-01_aviation.md`](experiments/2026-11-01_aviation.md)。
