# 真实性升级 v3：民航机载 RGB / IR / RD

2026-11-01（Asia/Shanghai）。本轮在已有生成器上实际实现了模型、成像和数据验收改进。
目标是减少可明确复现的仿真假象；**并不代表与某一真实设备完成了标定**。
三名子智能体分别负责材质、红外/大气、雷达/质量；主控负责光学、时序、集成与最终验证。

## 1. 已落地的变化

| 环节 | 之前的问题 | v3 行为 |
|---|---|---|
| 资产 | 导入后丢材质/UV；统一灰色 | 保留逐面源材质、UV、MTL；NASA 原始 GLB 的 PBR 节点和贴图复用于共用几何 |
| 几何 | 顶点聚类产生重复面，Blender 独立删面后材质错序 | 所有模态共用清理后的网格，面属性随同一索引保留 |
| 朝向 | 两模型机鼻在 −X，却把 +X 当前向 | 转换器统一机鼻 +X，沿速度设置 yaw 时不再倒着飞 |
| 材质物理 | 所有面使用对象单材质 | 显式源材质 → 物理材质映射；未映射项目与先验假设写入报告 |
| RGB | 理想渲染，缺少光路与传感器链 | 场景线性 RGB → 高度大气/空气光 → PSF → 光电子统计/读出噪声/固定 PRNU → 计数与 sRGB 显示 |
| 时间 | 曝光仅有字段 | RGB 使用 Cycles 在两端位姿间积分运动曝光；IR 曝光和雷达积累期运动仍明确标为未实现 |
| IR 背景 | 一大片地面按三角面中心距离消光，出现面片条纹 | 栅格后按像素深度进行斜程传输与路径辐射 |
| 大气 | 20 km 高空路径沿用全程海平面消光 | 可配置气溶胶/干空气/水汽等尺度高度，解析斜程消光和分层热辐射 |
| 热分布 | 每帧面片随机纹理闪烁、整物体温度覆盖 | 物体局部稳定温度纹理，按材质/组/局部范围标注热源 |
| 亚像素 | 漏采样的小目标被强行填成一个满信号像素 | 新模式按子样本覆盖率积分，保留部分覆盖和无有效观测的情况 |
| RD 检测 | 解析先验判定检出，不保证落在实际图像峰值 | 从实际 RD 峰值过门限，再关联模拟真值；未关联峰单独记录 |
| 噪声 | FFT 窗增益、最大值合成与门限不一致 | 按窗函数能量和独立多波束最大值分布计算热噪声门限 |
| 配准 | 主要比较同源投影框 | 独立比较 RGB/IR 实际实例图、深度、质心、IoU；稀疏小目标标为支持不足 |
| 工程 | Blender 脚本失败可能进程仍返回 0；旧文件可误当新结果 | 检查 Python 错误、输出时间；每次构建禁止覆盖并保留源码快照与哈希 |

另修复 Planck 波段数值积分端点偏差、红外高增益 16-bit 回绕、跨近裁剪面的地面孔洞、
单雷达波束不居中、视场外目标被补采样、量程边缘峰值被强行夹断等问题。

## 2. 运行方法

在项目根目录的 PowerShell：

```powershell
# 安装 CPU 仿真依赖；Blender 使用本机安装的 4.5 LTS
.\env\Scripts\python.exe -m pip install -r requirements.txt

# 首次准备模型；转换器已修正前向。已有旧 OBJ 也需要重新转换
.\env\Scripts\python.exe tools/fetch_aviation_models.py
.\third_party\blender\blender.exe -b --factory-startup -P tools/prepare_aviation_models.py

# 核心物理与回归检查
.\env\Scripts\python.exe -m simkit selftest
.\env\Scripts\python.exe -m unittest discover -s tests -v

# Blender 专项检查（实际材质、深度和运动曝光）
.\third_party\blender\blender.exe -b --factory-startup -P tests/blender_material_probe.py
.\third_party\blender\blender.exe -b --factory-startup -P tests/blender_sensor_probe.py

# 新模式：两模型 × 三种双机运动。必须使用未存在的输出目录
.\env\Scripts\python.exe tools/build_aviation.py --out out/aviation_realism_v3 -n 4 --dt 0.2 --realism
.\env\Scripts\python.exe tools/check_aviation.py out/aviation_realism_v3

# 可选对照图（需 Pillow）
.\env\Scripts\python.exe tools/aviation_preview.py out/aviation_realism_v3
```

4 帧仅为成像和质量验收，不能用于持续跟踪性能结论。
更长序列可改 `-n 120 --dt 0.05`，但仍需更多模型、独立轨迹和场景，按组划分数据。
不加 `--realism` 保留旧基线的单材质/均匀大气配置路径；代码层面的确定性缺陷修复仍生效。

生成器输出 `build_manifest.json`：保存命令、环境、Git 基线/脏状态、源码/配置/资产哈希和各场景完成状态。
`_source_snapshot/` 保存生成时的源码副本，避免尚未提交时只能查到哈希、无法还原文件。
大模型和所有输出目录被 Git 忽略，推送时只上传源码、文档、测试与来源清单。
CI 配置模板见 [`ci/selftest.yml.example`](ci/selftest.yml.example)。本次推送的 OAuth 授权没有
`workflow` scope，不能直接上传 `.github/workflows/selftest.yml`；可启用文件保留在本地，
线上未启用该 workflow，不能称线上 CI 已运行通过。

本次最终六场景另有一次可复现的标签修复（对象 ID/name 映射问题），原始渲染和传感器数组未改。
`visibility_finalization.json`、`_before_visibility_fix/` 和修复脚本副本记录了前后哈希。
未来用当前已修复的核心代码生成时无需这一步；详见本轮集成记录。

**分块限制**：RGB 自动曝光当前不保证整段/分块选中相同测光帧。若要求逐像素可复现，
请固定 `optical.auto_exposure=false` 和曝光参数，并做实际分块检查；不能沿用旧文档的无条件一致承诺。

## 3. 新输出与检查语义

- `raw/optical/*.npz`：场景线性 RGB、接收线性 RGB、整数计数、透过率、实例 ID 和相机前向 Z 深度。
- `raw/ir_mwir`、`raw/ir_lwir`：辐亮度、前向 Z 深度、实例 ID；子采样时另存目标覆盖率。
- `labels/optical`：源材质报告、传感器模型、实际实例通道可见性、运动曝光是否启用。
- `labels/radar`：实际单元位置、实测峰功率、门限/窗增益、真实与模糊速度、未关联峰。
- `observations`：标定、双机状态、部件热源匹配面数和面积、参数假设与时间约定。
- `quality.json`：投影契约检查与真实几何通道检查分别记录；“未验证”和“支持不足”不会伪报零误差。

Cycles 的 Z/Object Index 通道不做抗锯齿，也不代表模糊后图像的亮度轮廓；有运动曝光时通道的采样与积分图不同。
本机 Blender 4.5 的实际 10 m 平面测试确认 Z 通道为相机前向深度，不应当作欧氏射线距离使用。
IR 子样本模式返回像素内最近子样本的深度/实例；质量报告会声明采样不同。
因此本轮报告的质心/IoU 是**独立渲染的几何对应性**，不宣称所有模态亮度、热轮廓或曝光积分像素完全相同。

RD 的 Pfa 是局部峰筛选前、每个单元、独立热噪声假设下的概率；人工相干杂波不服从这一概率。
未关联峰不能统一称作热噪声虚警；真正的距离/速度分辨率仍由波形与采样决定，PNG 尺寸不是物理分辨率。

## 4. 热源和大气的适用范围

B777 与 SIERRA 热源是人工检查几何后按窄金属部位标注的**研究热通量**，不是实测发动机温度或尾焰模型。
配置同时记录范围、源材质名和实际匹配面积，避免热区悄悄覆盖整片机翼或没有选到任何面。
目前仍采用稳态热平衡，没有完整传导、热惯性、发动机气体谱或高速气动加热。

高度剖面是平地球、宽波段工程近似，没有逐谱线气体数据库、三维云体、折射、湍流或实测气象剖面。
RGB 空气光使用显式声明的线性颜色近似；光电子响应是相对场景线性单位的模型，没有绝对光谱辐射定标。
PBR 贴图使外观更完整，但 RGB 材质不能自动决定真实红外发射率与雷达散射，物理映射仍需测量或文献先验。
