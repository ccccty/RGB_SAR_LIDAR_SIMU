## 一、总结论（先看这里）

1. **真正"免费可下"的商业级工具只有 DIRSIG**：软件本身免费（Cornerstone Edition），但必须先自费参加 RIT 官方培训课，且软件受美国 EAR-99 出口管制，需通过 RIT 法务背景审查——**国内单位/个人获得难度高，需自行评估出口管制合规风险**。
2. **MuSES / OKTAL-SE / JRM 均无自助下载或公开评估版**，只能走"联系销售申请 Demo/评估"的商务流程。
3. **Presagis（SensorVision / Vega Prime）产品线已于 2024 年底关停**，实体不再运营，由 CAE 承接存量合同义务；传感器产品线的后继品牌为 Ondulus。不再存在公开 trial。
4. **公开数据库是本次调研最有价值的部分**，全部可合法免费获得：ECOSTRESS 光谱库可直接下载（免注册），HITRAN 注册免费，ITU-R P 系列建议书官方免费 PDF，SMARTS 注册免费，LOWTRAN7 有合法开源 Python 封装。
5. **开源渲染引擎（Mitsuba 3 BSD、POV-Ray AGPL）+ 公开数据库**是国内条件下最现实、最合规的自建 EO/IR/雷达仿真技术路线。

## 五、商业软件 REA/Ghidra 静态分析价值评估（若拿到合法副本）

**总体判断：对这些成熟商业仿真件做逆向，"参数与数据"价值远大于"代码逻辑"价值。**

1. **可提取内容分层**：
   - **高价值、易提取**：字符串表（传感器参数命名、错误信息暴露的内部模块结构）、内嵌数据文件（材质热物性表、光谱 LUT、大气查表、传感器预设参数——JRM FAQ 明确其 SDK 附带 notional 参数集，这类参数就躺在 dll 数据段里）、文件格式解析逻辑（理解其场景/材质文件 schema，便于自建转换器）。
   - **中等价值**：GUI 暴露的参数范围与默认值（反映工程经验边界）、DLL 导出表（API 结构）。
   - **低价值/不划算**：核心求解器算法（热平衡求解、光谱渲染、多次反射）——编译后为高度优化的数值代码，逆向成本极高，而这些算法的理论基础在 SPIE 会议论文、厂商技术手册、学位论文中均已公开（JRM FAQ 甚至自述 2005 年与 MuSES 做过对标评估）。
2. **合规约束**：即便持有合法副本，**EULA 普遍禁止逆向工程**（美国 DMCA 互操作例外、欧盟软件指令例外适用范围窄）。本团队的使用场景若涉及商业产品或对外发布，逆向 EULA 受限软件有法律风险；仅限"持有合法许可 + 内部研究、不输出其代码/数据"的灰色安全区。
3. **结论**：**不值得为逆向而逆向**。正确姿势是：公开论文/手册学方法 → 公开数据库（ECOSTRESS/HITRAN/ITU-R/SMARTS）拿数据 → 开源引擎（Mitsuba 3/lowtran/RaySAR）搭管线 → 仅在"已有合法许可的商业件参数标定"场景下用 REA/Ghidra 做有限的数据提取。

## 六、给项目的技术路线建议

1. **材质光谱/发射率**：ECOSTRESS 光谱库整库下载（免费直链），建立自己的材质库索引。
2. **大气模型**：LOWTRAN7（lowtran 包）做快速估算 + HITRAN/HAPI 做高精度逐线 + ITU-R P.676/P.837/P.838 做毫米波/雷达频段衰减 + SMARTS 做太阳光谱辐照基准。
3. **渲染/仿真内核**：Mitsuba 3（BSD，光谱+可微分）为光电/红外主框架；SAR 方向以 RaySAR 为参照实现。
4. **商业件**：暂不采购；若未来有对标需求，优先走 DIRSIG（培训+审查流程可先行摸底）或 MuSES（Demo 申请）官方渠道评估。
5. **合规底线**：所有软件只走本报告所列官方入口；EAR/ITAR 类产品（DIRSIG EAR-99、JRM 部分参数 ITAR）在获取前必须完成单位内部出口管制合规审查。
